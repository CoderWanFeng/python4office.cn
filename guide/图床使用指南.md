# 图床使用指南

> **适用范围**：本项目所有 Markdown 文档里的图片资源——如何把本地图片上传到 GitHub 图床，以及如何在文章中引用图床链接。
> **本指南从 `普通文章写作指南.md` 第九章「图片与媒体素材规范」中抽取图床相关内容独立成文。** 图片来源选择、尺寸规范、封面视觉风格等仍以原指南为准。
>
> **最后更新**：2026-11-06（v1）

## 二、上传流程（4 步）

### 2.1 准备图片

图片先放在**临时目录**周转，**不允许**长期存进 `source/img/` 或 `hexo/hexo/source/_posts/**/` 等本地目录再引用相对路径。

文件名硬性规则（同 `普通文章写作指南.md` 12.1）：
- 中文/英文标点一律用中横线 `-` 替代
- 禁止包含：`%`、`?`、`#`、`&`、空格、`，`、`。`、`、`、`：`、`；`、`（`、`）`
- 建议格式：`<日期>-<主题>-<用途>`，例如 `1106-booklist-cover-v3.jpg`

### 2.2 PicGo 上传

**单张**：

```bash
npx --yes picgo \
  -c /Users/wanfeng/.picgo/config.json \
  upload --format json /临时目录/图片.png
```

**批量**（当前目录所有 png）：

```bash
npx --yes picgo -c /Users/wanfeng/.picgo/config.json upload --format json "*.png"
```

返回 JSON 示例：

```json
[{
  "imgUrl": "https://github.com/CoderWanFeng/img-cdn/1106-booklist-cover-v3.jpg",
  "fileName": "1106-booklist-cover-v3.jpg",
  "size": 458349,
  "width": 3750,
  "height": 1600
}]
```

### 2.3 转成 Raw 直链（关键一步，不能省）

PicGo 返回的 `imgUrl` 是 GitHub **页面地址**，浏览器打开是 HTML 页面而不是图片，**必须手动转换**：

| 转换前（PicGo 返回） | 转换后（写入 Markdown） |
|---|---|
| `https://github.com/CoderWanFeng/img-cdn/<文件名>` | `https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/<文件名>` |

**转换规则**：域名 `github.com` → `raw.githubusercontent.com`；路径中插入 `/master/`。

### 2.4 验证

```bash
curl -sS -L -o /dev/null -w "%{http_code} %{size_download}" \
  "https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/<文件名>"
```

期望：**HTTP 200** 且 `size_download` 与本地文件字节数一致（`stat -f%z <本地文件>`）。

## 三、图床链接在文档中的两种用法

### 3.1 封面图（front-matter `cover` 字段）

```yaml
---
title: 文章标题
date: 2026-11-06 22:30:00
tags: [公众号文章, 具体标签]
categories: [公众号文章]
cover: https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/1106-booklist-cover-v3.jpg
---
```

### 3.2 正文插图

图片放在它所解释的文字之后，前后留空行，下方用斜体标注来源：

```markdown
![OpenAI Preparedness Framework 官方文件](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/文件名.png)

*图片来源：[OpenAI Preparedness Framework](官方页面或官方文件链接)*
```

## 四、严禁使用的链接形式

| ❌ 禁用 | 原因 |
|---|---|
| `https://github.com/CoderWanFeng/img-cdn/xxx.jpg` | PicGo 返回的页面地址，非直链，无法作为图片显示 |
| `https://cdn.jsdelivr.net/gh/...` | 第三方 CDN 加速地址，非项目统一口径 |
| `http://website-python-1300615378.cos.ap-nanjing.myqcloud.com/...` | 腾讯云 COS 旧地址，须迁移替换 |
| 本地相对路径 `![](xxx.png)` | Hexo 构建时路径不稳定，且无法跨平台引用 |
| 长期存 `source/img/` 再引用 | 官网下载图片只做临时周转，上传后统一走 Raw 直链 |

> **不限制第三方图库 URL**：Pixabay、Pexels、Unsplash 等通用图库的官方外链可直接使用，无需二次上传。**只有从官网下载并经 PicGo 上传的图片，才统一使用本站 GitHub Raw 图床格式。**

## 五、本地图片处理惯例

- **默认保留**：上传成功后，本地图片作为备份源不删除（项目历史惯例）
- **例外**：用户明确要求删除本地图片时（如同系列多版本封面清理），按指令删除
- **判断方式**：查看同目录其他文章的图片管理方式，保持一致

## 六、快速检查清单

**上传前**：
- [ ] 图片在临时目录，未长期存本地
- [ ] 文件名符合命名规范（无中文标点、无空格）
- [ ] 图片内容与文章主题匹配

**上传后**：
- [ ] PicGo 返回的 `imgUrl` 已转成 `raw.githubusercontent.com` 直链
- [ ] `curl` 验证返回 HTTP 200
- [ ] 远程文件大小与本地字节数一致
- [ ] Markdown 中所有引用都是 Raw 直链，无 `github.com/...` 页面地址残留
- [ ] 正文图片下方已用斜体标注来源
- [ ] 封面来源已加入文末「参考链接」
