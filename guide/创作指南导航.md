# 创作指南导航

> 本文件是 **索引 / 导航文档**，不合并、不修改任何原始创作指南。
> 写某类内容前，先在本表找到「该看哪份指南」，打开原文按它的规则动笔即可。
> 所有路径相对于仓库根：`python4office.cn/hexo/hexo/source/_posts/`（下文省去此前缀）。

---

## 一、使用说明

1. 动笔前，先判断你要写的内容属于 **公众号文章 / 口播稿 / 每日聚合** 哪一类（见下方「总览表」）。
2. 按表找到对应指南的**真实路径**，打开原文。
3. 指南里写「去哪个目录写」，就在该内容线的 `_posts` 子目录下新建 `.md`。
4. 多份指南对同一规则有冲突时，**以本文「已知冲突与以谁为准」一节为准**，不要自行混用。

**范围说明**
- 收录 15 份 Markdown 指南 + 1 份 PPTX（共 16 个文件）。
- `口播稿创作指南.pptx` 为二进制，不提取文字，仅在对应条目链接原文件。
- `*.bak` 备份文件不收录。
- 原始指南文件一律不改动。

## 三、公众号文章类

> 含返佣推广、普通长文、B2B 长文、封面配图、排版发布、AI 热点新闻稿。

### 1. 返佣文章-公众号文章创作指南（cake-growth 返佣文「唯一标准」）
- **路径**：`ads/cake-growth/guide/返佣文章-公众号文章创作指南.md`
- **适用**：`ads/cake-growth/products/` 下所有厂商合作 / 返佣推广文章。指南自述为「cake-growth 下 products 目录创作的**唯一标准**，所有规则必须严格执行」。
- **关键规则**：
  - 正文禁止使用 Markdown `>` 引用块（会渲染成公众号灰条，是典型 AI 痕迹）；规则讲解区自身的警示块可保留。
  - 「相关阅读」**固定 3 条**（从 10 条候选库挑最相关的），明确「禁止全抄 6/10 条」。
  - 图床主推 **Pixabay**，Pexels 备胎，Unsplash 最后；禁止下载到本地。
  - 返佣链接「弱-强-最强」3 处递进（文首前 / 倒数第 2 节后 / 结尾 CTA）；链接须用「完整 URL 显示格式」。
  - 固定 Slogan 一字不差：`科技不高冷，AI很好用。我是晚枫，关注我，带你一起玩AI！`
  - 文件名所有标点用**英文中横线 `-`** 替代。
  - 合规红线：禁药品/医疗/金融投资建议类比；禁竞品贬低。
- **去哪写**：`ads/cake-growth/products/`

### 2. 公众号文章创作指南（通用 / 普通长文版）
- **路径**：`ads/guide/公众号文章创作指南.md`
- **适用**：非返佣的普通公众号长文（旧通用版）。
- **关键规则**：「相关阅读」**固定 6 条**固定模板链接（与返佣版 3 条冲突，见第四节）。其余结构、Slogan、排版与返佣版大体一致。
- **去哪写**：`公众号文章/`（或对应内容线目录）

## 六、已知冲突与「以谁为准」

多份指南对同一规则存在不同规定，写作时**按内容类型分流**，不要混用：

| 冲突点 | A 方规定 | B 方规定 | 以谁为准 |
|---|---|---|---|
| **相关阅读条数** | 返佣版：固定 **3 条**（且「禁止全抄 6/10 条」） | 通用 / workflow / AI热点新闻稿：固定 **6 条**模板 | **按内容类型**：返佣 / cake-growth 文章用 **3 条**；普通 / B2B / workflow / 热点新闻稿用 **6 条**。两者适用场景不同，不互相覆盖。 |
| **口播封面视觉** | 旧封面指南：暗底金字 + 发光阴影 | 视频指南 §2.6：统一 **swiss-grid**（白底红黑） | **以 swiss-grid 为准**。旧「暗底金字」方案已废弃，封面须与视频本体同风格。 |
| **图床** | 返佣版：主推 **Pixabay**，Pexels 备胎，Unsplash 最后 | 通用版历史曾推荐 Unsplash | **返佣文以 Pixabay 为准**；其他内容线未强制，可沿用各自指南，但返佣文须遵守 Pixabay 优先。 |
| **正文引用块 `>`** | 返佣版：公众号**正文禁止** `>` | 排版指南：鼓励用 `>` 做排版标注 | **不冲突，分工不同**：返佣版禁的是「发布到公众号的正文」；排版指南管的是「排版标注区」，可保留。 |
| **固定 Slogan** | 返佣版：`…带你一起玩AI！` | 各版基本一致 | 全站统一为：`科技不高冷，AI很好用。我是晚枫，关注我，带你一起玩AI！` |

> 说明：以上冲突源于指南在历史迭代中逐步分化（返佣版 2026-07-13 多次优化、视频版 2026-06-22 锁定 swiss-grid）。如需永久统一，建议后续把「相关阅读条数」「图床」「封面视觉」收敛为单一全局标准，再回填各指南。
