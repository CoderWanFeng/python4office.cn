## 使用说明

1. 写公众号文章到结尾「相关阅读」部分时，打开本文件
2. 从下方两个公众号的最新文章列表中，选取 **2-4 篇**与当前文章主题最贴近的链接
3. 复制标题和链接，粘贴到文章末尾的「## 相关阅读」部分
4. 选取原则：
   - **相关优先**：选与当前文章主题、工具、场景直接相关的文章
   - **混搭选取**：两个公众号的文章可以混搭，不限制各占几篇
   - **宁缺毋滥**：如果某篇文章与当前内容完全无关，不要硬凑
   - **篇数灵活**：最少 2 篇，最多 4 篇，按内容相关度决定——不必每篇都凑满 4 篇

## 自动更新机制

本文件由定时任务自动更新，配置如下：

| 项目 | 配置 |
|------|------|
| **执行工具** | `wechat-article-archive` skill |
| **执行频率** | 每 3 天一次（定时任务 ID: automation-1784994264841） |
| **数据来源** | 晚枫AI学习笔记、Python自动化办公社区 |
| **采集数量** | 每次采集最近 10 篇 |
| **存储策略** | **持续积累**：新采集文章与已有列表合并、按链接去重、按时间倒序排列，全部保留不淘汰 |
| **备用采集路径** | 当微信 API 限流时，改用 Web 搜索 + python4office.cn Hexo 源文件采集文章标题和发布日期，**仅收录能获取 mp.weixin.qq.com 直链的文章**，无法获取微信直链的文章暂不收录 |
| **输出文件** | 本文件（`相关阅读.md`） |

### 执行流程

1. 优先调用 `wechat-article-archive` skill 的 `discover_account_articles.py` 脚本，分别采集两个公众号的最近 10 篇文章
2. 如果微信 API 限流（ret=200013），启用备用路径：
   - 用 Web 搜索 + python4office.cn Hexo 源文件提取文章标题和发布日期
   - **只收录能获取到 mp.weixin.qq.com 直链的文章**，无法获取微信直链的文章暂不收录
3. 从已有表格中提取现有文章（标题、链接、发布时间），与新采集列表合并
4. **按文章链接去重**（同一篇文章只保留一条）
5. **按发布时间倒序排列**，全部保留（不限制篇数，持续积累）
6. 重新编号，更新本文件中对应的表格
7. 记录更新日志（注明本次新增几篇、累积总篇数）
