## 使用说明

1. 写公众号文章到结尾「相关阅读」部分时，打开本文件
2. 从下方两个公众号的最新文章列表中，选取 **2-4 篇**与当前文章主题最贴近的链接
3. 复制标题和链接，粘贴到文章末尾的「## 相关阅读」部分
4. 选取原则：
   - **相关优先**：选与当前文章主题、工具、场景直接相关的文章
   - **混搭选取**：两个公众号的文章可以混搭，不限制各占几篇
   - **宁缺毋滥**：如果某篇文章与当前内容完全无关，不要硬凑
   - **篇数灵活**：最少 2 篇，最多 4 篇，按内容相关度决定——不必每篇都凑满 4 篇

## 自动更新机制

本文件由定时任务自动更新，配置如下：

| 项目 | 配置 |
|------|------|
| **执行工具** | `wechat-article-archive` skill |
| **执行频率** | 每 3 天一次（定时任务 ID: automation-1784994264841） |
| **数据来源** | 晚枫AI学习笔记、Python自动化办公社区 |
| **采集数量** | 每个公众号最近 10 篇 |
| **输出文件** | 本文件（`相关阅读.md`） |

### 执行流程

1. 调用 `wechat-article-archive` skill 的 `discover_account_articles.py` 脚本，分别采集两个公众号的最近文章列表
2. 提取文章标题、发布时间、链接
3. 按时间倒序排列，每个公众号保留最近 10 篇
4. 更新本文件中对应的表格
5. 记录更新日志

```bash
# 采集示例（晚枫AI学习笔记）
python3 ~/.workbuddy/skills/wechat-article-archive/scripts/discover_account_articles.py \
  --account "晚枫AI学习笔记" \
  --limit 10 \
  --output "tmp/wanfeng-ai-candidates.csv"

# 采集示例（Python自动化办公社区）
python3 ~/.workbuddy/skills/wechat-article-archive/scripts/discover_account_articles.py \
  --account "Python自动化办公社区" \
  --limit 10 \
  --output "tmp/python-office-community-candidates.csv"
```

> ⚠️ 首次运行需要扫码登录微信公众平台，登录态保存在 `~/.cache/wechat-article-archive/session.json`。后续运行自动复用。会话失效时脚本会自动删除缓存，下次运行重新扫码。
