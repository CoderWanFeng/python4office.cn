# AI 线下活动总结

本目录用于存放 AI 线下活动（meetup、workshop、峰会、分享会等）的总结文章。

## 命名规范

```
YYYYMMDD-活动名称-活动地点.md
```

示例：

- `20261020-meetup-ai-creator-beijing.md`
- `20261105-ai-summit-shanghai.md`

## front-matter 模板

```yaml
---
title: YYYYMMDD-活动名称-活动地点
date: 2026-MM-DD HH:MM:00
tags: ["AI活动", "线下活动", "城市", "活动类型"]
categories: ["线下活动", "AI活动"]
cover: https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/ai-event-XXX-cover.jpg
---
```

## 写作参考

请参考 [普通文章写作指南](../../../../../guide/普通文章写作指南.md) 写作：

- 字数 ≥ 1500
- front-matter 必填 title / date / tags / categories / cover
- 图片统一使用 GitHub Raw 图床地址
- 配图用 PicGo 上传到 `CoderWanFeng/img-cdn` 仓库
- 文末使用标准 Slogan：「科技不高冷，AI 很好用。」
