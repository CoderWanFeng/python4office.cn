大家好，我是程序员晚枫。

今天打开 ChatGPT 桌面版，我看到一个挺实在的邀请活动：

**邀请一位符合条件的朋友，对方发送第一条消息后，双方各得 1,000 额度。**

而且页面显示，每个月最多可以获得 3 次邀请奖励。

先别急着把计算器按冒烟。这里的“1,000 额度”不是 1,000 美元，也不是可以拿去调用 API 的余额。

> **它是这次活动发放的 Codex 使用额度，能增加使用量，但不能提现、转卖或换成现金。**

## 1000额度是真的，但有4个前提

从我当前账户显示的活动页面看，这次规则很直接：邀请好友使用新版 ChatGPT 桌面版，在对方发送第一条消息后，邀请人和受邀人各获得 1,000 额度。

但这不是“随便填个邮箱就到账”。

| 关键问题 | 当前页面显示的规则 |
| --- | --- |
| 谁能获得 | 邀请人和受邀人双方 |
| 奖励多少 | 每人 1,000 额度 |
| 何时发放 | 受邀者发送第一条消息后 |
| 每月上限 | 最多获得 3 次邀请奖励 |
| 受邀者要求 | 过去 2 个月未使用桌面版 |
| 重复邀请 | 不能已有有效推荐邀请 |

OpenAI 的官方说明还补充了一个容易忽略的细节：**发出邀请时不会立即获得奖励。**

只有受邀者通过官方流程接受邀请、满足资格、完成指定的 Codex 操作，并通过必要检查后，奖励才会发放。

这意味着，即使你成功发出了邮件，只要对方没有完成第一条消息，或者账号不符合资格，最终都可能没有奖励。

另外，不同方案、地区、工作空间和活动批次，奖励金额、邀请次数、到期时间都可能不同。

所以这篇文章介绍的是**我在 2026 年 8 月 4 日实际看到的这一档活动**。如果你的页面显示不同数字，请以自己账户里的弹窗为准。

---

## 真正的领取动作，是完成第一条消息

如果你的账户符合资格，可以在 ChatGPT 桌面版左下角的个人资料菜单中寻找邀请入口。

整个过程可以分成 5 步：

1. 打开 ChatGPT 桌面版，进入左下角个人资料菜单；
2. 选择“邀请朋友”，查看当前奖励和资格要求；
3. 填写朋友的电子邮箱并发送官方邀请；
4. 朋友通过邮件接受邀请，登录或安装 ChatGPT 桌面版；
5. 朋友在 Codex 中发送第一条消息，等待系统完成资格检查并发放奖励。

这里最容易漏掉的是第 5 步。

对方只打开邮件、下载软件还不够，必须完成活动要求的实际操作。按照我看到的页面，就是发送第一条消息。

第一次不知道问什么，可以从一个很小的任务开始：

> 帮我看看这个文件夹是做什么的，并告诉我应该从哪个文件开始读。

不需要一上来就让 Codex 写一个大型项目。先让它读取资料、解释文件或者整理下一步任务，更容易看懂桌面版和普通网页聊天的区别。

### 为什么奖励按额度算，而不是按消息算

这里顺便讲一个 AI 使用知识。

同样是发送一条消息，有人只是问一句话，有人会让 Codex 读取几十个文件、搜索资料、运行工具并持续工作半小时，两者消耗的计算资源完全不同。

所以 AI 智能体很难简单按“可以聊多少次”计算。任务使用什么模型、读取多少上下文、调用多少工具、运行多长时间，都会影响消耗。

**额度更像一张使用卡，而不是固定次数的电影票。**

这也是为什么官方不会承诺“1,000 额度一定能完成多少个任务”。任务越复杂，额度消耗通常越快。

## 这4种操作，最容易让奖励不到账

第一种，是邀请最近已经用过 ChatGPT 桌面版的人。

我看到的活动明确要求，受邀者在过去 2 个月内不得使用过 ChatGPT 桌面版。老用户即使收到邮件，也可能无法通过资格检查。

第二种，是同一个人同时接受多份邀请。

OpenAI 官方说明指出，如果受邀者收到多个推荐邀请，通常只有第一个符合条件的推荐可能计入奖励。重复邀请不会叠加。

第三种，是自己邀请自己。

自我邀请、用邮箱别名绕过限制、同一设备关联的自我推荐，以及其他疑似滥用行为，都不符合资格。为了薅 1,000 额度把账号折腾出风险，属于羊毛没拿到，先把羊吓跑了。

第四种，是把额度当成 API 余额。

除非活动页面明确另有说明，否则推荐额度通常只适用于活动指定的 Codex 或 ChatGPT 体验，不能用于 OpenAI API，也不能兑换现金、转让或出售。

奖励也可能存在有效期。当前官方说明没有为所有活动规定同一个过期时间，因此获得奖励后，最好马上查看账户里的具体期限。

---

这次活动最有价值的地方，不只是多送了一点额度。

它实际上降低了朋友第一次体验 Codex 的门槛：你不用先解释一大堆模型、终端和开发工具，只需要发出邀请，让对方在桌面版里完成第一条真实任务。

如果你身边正好有过去两个月没有用过 ChatGPT 桌面版、又想尝试 Codex 的朋友，这个活动值得参加。

但如果对方不符合条件，也不用为了奖励反复注册新号。

> **好的邀请，是让两个人都多一次真实体验；不是为了薅羊毛，把产品规则研究成刑侦现场。**
