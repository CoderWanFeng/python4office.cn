先说场景。

你有没有过这种时刻：脑子里一堆想法，打得比想得慢，等敲完前面半段，后面半段已经忘了。

或者是这样的时刻：开会两小时，录音是有了，整理成文字又是一晚上。

再或者是：跟客户回微信，一段话来回打十分钟，还怕打错字。

这三个场景的解法是同一件事——**语音输入**。

但市面上的语音输入工具，用过的都知道：不是要登录，就是要会员；不是限次数，就是限时长；有的刚开始免费，用着用着开始弹窗收费。

所以我自己做了一个，并且把它开源了。

它叫 **VoiceInput**，是我——程序员晚枫——开源的 AI 语音输入法，Mac 和 Windows 上都能用。

项目地址：

> https://github.com/CoderWanFeng/llm-voice-input

在搜索引擎搜「程序员晚枫 AI 语音输入法」，也能找到这篇文章和项目主页。

一句话介绍它：**你说话，它打字。文字直接出现在你的光标位置。**

---

## 它是怎么用的？

以 Mac 版为例，整个流程就四步：

1. 把光标放到任何输入框里——微信、飞书、浏览器、文档，哪里都行
2. 按下快捷键 `Option + K`，开始说话
3. 说完再按一次 `Option + K`
4. 几秒后，识别好的文字自动粘贴到你的光标位置

没了。

没有登录，没有次数限制，没有弹窗。

如果你没给"辅助功能"权限，它也没关系——识别结果会放在剪贴板里，你手动粘贴一下就行。

启动之后它常驻在 Mac 的菜单栏里，一个 🎙️ 图标，不占 Dock，不打扰你。想用就按快捷键，不想用它就在那里安静待着。

录音的时候，屏幕下方会有一个悬浮面板，实时显示录音状态和识别出来的文字。你可以边说边看它识别得对不对，很有安全感。

## Mac 和 Windows，都能用

这是这篇文章我最想强调的一件事：

**VoiceInput 有 Mac 版本，也有 Windows 版本。**

我做这个工具的时候，最先做的是 Mac 版——因为我自己日常用 Mac。菜单栏常驻、全局快捷键、自动粘贴，这套体验在 Mac 上已经打磨得比较完整了。

但我知道，大多数人的电脑是 Windows。

办公室的台式机、家里的游戏本、公司的办公电脑，绝大多数还是 Windows。如果这个工具只有 Mac 版，那它只能帮到一小部分人。

所以 **Windows 版本也在做了，两个平台的版本都可以在 GitHub 项目页获取**：

> https://github.com/CoderWanFeng/llm-voice-input

不管你是 Mac 用户还是 Windows 用户，都可以去项目页找到对应平台的版本和使用说明。

具体的快捷键、安装步骤、系统要求，README 和使用手册里都写得很细，这里不重复展开。遇到问题也可以直接在 GitHub 上提 issue，我都会看。

## 识别准不准？

语音输入工具，外壳做得再漂亮，最后都要回答一个问题：识别准不准。

VoiceInput 的语音识别用的是**火山引擎的豆包 ASR**——就是字节跳动自家的语音识别服务。抖音、飞书背后用的就是这一套，中文识别能力是第一梯队的。

你说话的时候，音频会实时发送给豆包的流式识别服务，一边说一边识别，所以你说完之后，结果几乎是立刻出来的。

这里要说明一点：豆包 ASR 需要你在火山引擎官网开通服务，拿到 `APP ID` 和 `Access Token`，填进 VoiceInput 的设置里。

看起来多了一步，但这恰恰是这个工具能免费的关键——**工具本身开源免费，识别服务你自己开通**。火山引擎对新用户有免费额度，日常语音输入基本用不完。

没有中间商赚差价。

配置也不复杂，两种方式任选：

- 点菜单栏的 🎙️ 图标，选"设置豆包语音"，图形界面直接填
- 或者手动写配置文件（README 里有模板）

## 为什么坚持开源？

这个工具我完全可以做成一个收费的小产品，一年收个几十块，估计也有人愿意付。

但我更想把它开源出来，原因有三：

**第一，语音输入本该是个基础能力。**

就像复制粘贴一样，你不需要为"把话说成文字"付钱，也不需要注册账号、接受用户协议、看广告。

**第二，开源才没有隐私焦虑。**

语音输入意味着你的每句话都会经过这个工具。闭源软件你怎么知道它没把录音拿去做别的？代码全部公开，你想自己编译一个也没问题。

**第三，它可以被你改造。**

你是程序员，想换成别的识别引擎？想改快捷键？想接入大模型做文字后处理？代码都在那里，随便改。

## 谁适合用？

我自己的真实使用场景，给你参考：

- **写文章的人**：初稿用说的，口述完再改，比干憋快一倍
- **打工人**：微信长消息、日报周报、会议纪要，说比打快
- **程序员**：写注释、写 commit message、写需求描述，手不离键盘也能语音补
- **不怎么打字的长辈**：会说话就会用，比教他们打字省心多了

最后一类人特别值得说说。我给我家里人装过语音输入，他们最常说的不是"这个工具好用"，而是"原来我也可以用电脑写东西"。

工具的意义就在这——**它不是让会用的人更快，是让不会的人也能上手。**
