### 口播正文（完整连贯版·口语化）

大模型收费，关我什么事。今天带大家免费用的是——一口气，二十个。

以前免一个模型不算稀奇了，DeepSeek 讲过，GLM 讲过。今天这个路子狠在：一个账号，一个 Key，二十多个旗舰模型全免费。DeepSeek，免费。Meta 的 Llama 4，免费。NVIDIA 的推理怪兽，免费。连 OpenAI 自己开源的那个 120B——也免费。

路子叫 OpenRouter，大模型界的携程。它自己不造模型，把全世界几十家厂商的 API 全聚到一个入口，你在上面搜 free，出来的全是免费的，带冒号 free 后缀的随便挑。

怎么用？三步。第一步，打开 openrouter.ai，Google 或者 GitHub 登录，不用信用卡。第二步，后台创建一个 API Key，复制。第三步，打开 Cherry Studio 或者 Chatbox 这种客户端，设置里把 Key 粘进去，模型选带 free 后缀的，开聊。不写代码，一分钟搞定。

写代码的兄弟更爽。它完全兼容 OpenAI 格式，你现有代码就改两个地方：base_url 换成 openrouter 的，model 换成冒号 free 结尾的——账单直接归零。

三个必试的。DeepSeek V4 Flash，百万上下文，省钱之王。OpenAI 开源的 gpt-oss-120b，人家闭源版收费，开源版免费。NVIDIA 的 Nemotron 3 Ultra，550 亿参数的推理怪兽，也是白给。还有个懒人玩法：模型填 openrouter 斜杠 free，它自动帮你挑最合适的免费模型，选择困难症狂喜。

说下限制，免费账户每天 50 次、每分钟 20 次，个人日常完全够用。充 10 美元一次性解锁每天 1000 次，额度永不过期。最后一句良心话：免费模型的对话可能被拿去做训练，自己玩、做项目随便造，公司代码和客户数据别往上放。

我是晚枫，免费大模型只在这里讲。不想折腾 API 的，下期讲一个不用翻墙、永久免费的国内平台，评论区扣 1，安排。
