## 🥉 Bronze · Bootcamp Pass

### 适用对象

- 刚完成 4 天 Bootcamp 的学员
- 想转岗 AI 落地的工程师

### 能力要求

| 维度 | 要求 |
|---|---|
| 业务理解 | 能做 1 次模拟客户访谈 + Stakeholder Map |
| 技术选型 | 能用决策矩阵 + ADR 选模型 |
| 工程实现 | 能搭 1 个可用的 Agent Demo（含 RAG + 工具调用） |
| 安全意识 | 能完成 10 题红队测试 + 4 层防护基础 |

### 通过条件（提交清单）

- [ ] 《客户业务画像 v0.1》1 份
- [ ] Stakeholder Map 1 张
- [ ] ADR v1.0 1 份（模型选型）
- [ ] 1 个 Agent Demo 代码（GitHub）
- [ ] 50 题评估集 + 评估报告 v1.0
- [ ] 10 题红队测试报告
- [ ] 《安全审查报告 v1.0》
- [ ] mentor 1v1 review 通过

### 解锁权益

- ✅ 进入 Residency 资格
- ✅ "Frontier Deployed Engineer - Apprentice" 身份认证
- ✅ 加入 FDE 学员社区

## 🥈 Silver · Residency Pass

### 适用对象

- 完成 12 周 Residency 的学员
- 独立完成 1 个企业级 AI 项目的工程师

### 能力要求

| 维度 | 要求 |
|---|---|
| 客户嵌入 | 能独立完成客户业务画像 v1.0 |
| 方案设计 | 能用 C4 Model 画 4 张视图 + 写 3-5 份 ADR |
| LLM 工程 | 能交付 1 个生产级 RAG + Agent 系统（准确率 ≥85%） |
| 企业集成 | 能把 AI 接入客户的 OA / CRM / SSO |
| 部署能力 | 能用 Docker Compose + Helm 部署到客户环境 |
| 安全审查 | 能完成 30 题红队测试 + 4 层防护 |
| 可观测性 | 能接 Prometheus + Grafana + 写 SLO 报告 |
| 业务交付 | 能定义北极星指标 + 写业务方周报 + 沉淀 Playbook |

### 通过条件（提交清单）

**12 周 8 大模块全部交付物：**

- [ ] 模块 1：《客户业务画像 v1.0》+ Stakeholder Map
- [ ] 模块 2：C4 视图 4 张 + ADR v1.0 + 5 页技术 PPT
- [ ] 模块 3：RAG + Agent 系统 + 50 题评估报告
- [ ] 模块 4：端到端集成（含 SSO + RBAC）
- [ ] 模块 5：docker-compose.yml + Helm Chart + 部署手册
- [ ] 模块 7：《安全审查报告 v2.0》+ 30 题红队报告
- [ ] 模块 6：Prometheus + Grafana 看板 + SLO 报告 + 混沌演练记录
- [ ] 模块 8：北极星指标看板 + 业务方周报 + Playbook

**额外要求：**
- [ ] 客户业务方签字确认（项目真实运行）
- [ ] mentor 1v1 review 通过（12 周末）
- [ ] 通过 Gold 级 FDE 的项目验收

### 解锁权益

- ✅ "Frontier Deployed Engineer - Junior" 正式认证
- ✅ 进入 FDE 高级人才库
- ✅ 有资格申请 Gold 阶段
- ✅ 客户续约 / 新客户对接优先权

## 🥇 Gold · Deployment Lead

### 适用对象

- 已获 Silver 徽章 + 主导过 3+ 个生产项目
- 内部想成为 Mentor / Team Lead 的工程师
- 想做 AI 公司 FDE 团队建设的人

### 能力要求

| 维度 | 要求 |
|---|---|
| 项目交付 | 主导 ≥ 3 个生产级 AI 项目（每个 ≥¥100 万合同额） |
| 客户成功 | ≥ 1 个客户续约 / 扩展案例 |
| 团队建设 | 培养 ≥ 1 名 Junior FDE（获 Silver 徽章） |
| 知识沉淀 | 主导 ≥ 3 个 Playbook 文档（覆盖 3 种项目类型） |
| 行业影响 | 在公司内 / 行业会议做过 ≥ 3 次 FDE 主题分享 |
| 安全合规 | 主导 ≥ 3 次完整红队测试（含红队失败案例复盘） |

### 通过条件（提交清单）

**项目维度（≥ 3 个）：**
- [ ] 项目 1：客户名称 / 合同额 / 关键指标 / 验收报告
- [ ] 项目 2：客户名称 / 合同额 / 关键指标 / 验收报告
- [ ] 项目 3：客户名称 / 合同额 / 关键指标 / 验收报告

**团队维度：**
- [ ] 培养的 Junior FDE 名单 + 他们的 Silver 徽章编号
- [ ] 1 对 1 mentor 记录（≥ 24 次 / 12 个月）

**知识沉淀：**
- [ ] Playbook 1：[项目类型 A]
- [ ] Playbook 2：[项目类型 B]
- [ ] Playbook 3：[项目类型 C]

**分享与影响：**
- [ ] 内部技术分享 / 行业会议演讲记录
- [ ] 公开博客文章 / GitHub 仓库 star 数（若有）

### 解锁权益

- ✅ "Frontier Deployed Engineer - Senior" 正式认证
- ✅ "Deployment Lead" 头衔（可印名片）
- ✅ 有资格担任 Bootcamp 讲师 / Residency mentor
- ✅ 加入 FDE 顾问委员会
- ✅ 优先获得行业资源对接（客户 / 项目 / 投资）

## 🎯 评估流程

### Bronze 评估

1. 提交交付物清单
2. 1 次 1v1 mentor review（30 分钟）
3. 1 次代码 review（Demo Agent GitHub）
4. 通过 → 发 Bronze 徽章 + 数字证书

### Silver 评估

1. 提交 12 周全部交付物
2. 2 次 1v1 mentor review（每次 60 分钟）
3. 1 次客户业务方远程访谈（确认项目真实运行）
4. Gold 级 FDE 项目验收（远程 1 小时）
5. 通过 → 发 Silver 徽章 + 数字证书 + LinkedIn 加认证

### Gold 评估

1. 提交 3 个项目 + 团队建设 + Playbook 清单
2. 委员会评审（3 名 Gold FDE + 1 名行业专家）
3. 现场答辩（半天）
4. 通过 → 发 Gold 徽章 + 数字证书 + 顾问委员会席位
