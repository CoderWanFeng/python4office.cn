# FDE 前沿部署工程师实战课

> **对标 Anthropic Claude Frontier Academy，做一套本土化的 FDE 培养体系**

> 🐍 全网 30万+ 粉丝 | 帮企业研发/数据团队把 AI Coding 和 AI Agent 落地为团队生产力

> **💡 一句话总结**：4 天 Bootcamp 高强度集训 + 12 周 Residency 真实项目驻场，从拿到客户模糊需求，到把前沿大模型端到端部署到企业生产环境，跑出业务指标。

---

## 🎯 课程三个特点

> **📚 系统**：完全对齐 Anthropic Claude Frontier Academy 的"4天 Bootcamp + 12周 Residency"双阶段模型，覆盖 FDE 全链路 8 个核心能力模块
>
> **🔧 实战**：学员必须自带真实客户项目进场，全程由资深 FDE 导师陪做（1v1 code review + 每周全员复盘）
>
> **⚡ 不啰嗦**：每个能力点对应一个实操评估，对应一个徽章可解锁

---

## 🚀 课程背景

**2026 年 10 月 2 日，Anthropic 宣布投入 1 亿美元成立 Claude Frontier Academy，目标到 2027 年底培养 1 万名前沿部署工程师（Frontier Deployed Engineer，FDE）。**

首批合作机构包括埃森哲、麦肯锡、贝恩、摩根士丹利等。课程采用医学院住院医师（Residency）的培养模式：

- **4 天线下密集训练** —— 演练企业导入 Claude 的完整流程（挑选场景 → 构建方案 → 安全审查）
- **12 周驻场实战** —— 学员带真实客户项目进场，由 Anthropic 资深 FDE 当导师陪着做
- 通过分级实操拿到 **"Claude Frontier Deployed Engineer"** 认证徽章

这门课就是 **对标 Frontier Academy 的课程设计**，结合中国企业的真实场景，做一套本土化、可落地的 FDE 培养方案。

## 📖 课程大纲

### 阶段一 · 4 天 Bootcamp（集训）→ 🥉 Bronze

| 天 | 主题 | 实操评估 |
|---|---|---|
| **Day 1** | [FDE 角色与高能动性](./01-bootcamp-day1-high-agency) | 1 次模拟客户访谈 + Stakeholder Map |
| **Day 2** | [前沿模型与部署形态](./02-bootcamp-day2-model-selection) | 决策矩阵 + 1 份 ADR |
| **Day 3** | [Agent 系统构建实战](./03-bootcamp-day3-agent-build) | 限定时间内搭 1 个可用的 Agent Demo |
| **Day 4** | [安全、合规与红队演练](./04-bootcamp-day4-security-review) | 安全自审 + 红队演练 |

> 集训通过 → 解锁 🥉 Bronze · Bootcamp Pass Badge → 进入 Residency

---

### 阶段二 · 12 周 Residency（驻场实战）→ 🥈 Silver

| 周 | 主题 | 交付物 |
|---|---|---|
| **1-2** | [模块 1 · 客户嵌入与业务翻译](./05-residency-module1-customer-embedding) | 《客户业务画像 v1.0》+ Stakeholder Map |
| **3-4** | [模块 2 · 解决方案设计与 ADR](./06-residency-module2-solution-design) | 5 页技术方案 PPT + ADR v1.0 |
| **5-7** | [模块 3 · LLM 生产化工程（核心）](./07-residency-module3-llm-engineering) | 1 个可演示的 RAG + Agent 系统（覆盖 50 个真实问题） |
| **8** | [模块 4 · 企业系统集成](./08-residency-module4-enterprise-integration) | 端到端集成跑通（客户系统 → AI 服务） |
| **9** | [模块 5 · 私有化部署与基础设施](./09-residency-module5-private-deployment) | 部署到客户测试环境并跑通 |
| **10** | [模块 7 · 安全审查与合规闭环（贯穿全程）](./10-residency-module7-security-compliance) | 《安全审查报告 v1.0》+ 红队测试记录 |
| **11** | [模块 6 · 可观测性与稳定性](./11-residency-module6-observability) | 1 份 SLO 报告 + 1 次混沌演练记录 |
| **12** | [模块 8 · 业务指标与交付艺术](./12-residency-module8-business-metrics) | 1 份业务方周报 + 1 个 Playbook 文档 |

> 驻场通过 → 解锁 🥈 Silver · Residency Pass Badge → 获得 "Frontier Deployed Engineer - Junior" 认证

---

### 阶段三 · 能力分级与徽章体系

详细标准见 [13-badges-and-certification.md](./13-badges-and-certification)

| 徽章 | 等级 | 能力要求 | 对应身份 |
|---|---|---|---|
| 🥉 Bronze · Bootcamp Pass | 入门 | 完成 4 天集训 + 通过 4 个实操评估 | FDE Apprentice（学徒） |
| 🥈 Silver · Residency Pass | 进阶 | 完成 12 周驻场 + 上线 1 个真实业务集成 | Junior FDE |
| 🥇 Gold · Deployment Lead | 资深 | 主导 ≥ 3 个生产项目 + 通过安全审查 + 培养 ≥ 1 名 Junior FDE | Senior FDE / Mentor |

## 🎯 面向人群

### ✅ 适合

- 有 Python / 软件工程背景（建议先看 [Python 入门 15 讲](https://www.python-office.com/course/python-15.html)）
- 有 LLM 应用经验（用过 OpenAI / Anthropic / DeepSeek API）
- 想成为 AI 公司 FDE 或企业内部 AI 落地负责人
- 想从独立开发者转型做企业级 AI 项目的工程师

### ❌ 不适合

- 完全无工程背景者（请先学 [Python 零基础入门 23 讲](https://python4office.cn/course/AI/python-basics/)）
- 纯研究者 / 模型训练背景（请看 [AI 基础概念课](https://python4office.cn/course/AI/ai-basic-concepts/)）
- 只想做 Demo 不想上生产的人（FDE 是要担业务结果的）
