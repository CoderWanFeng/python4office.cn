## 一、AI Token 中转站（必选）

### 1.1 项目简介

AI Token 中转站，简单说就是**AI 模型的「代购平台」**。

各大 AI 公司（OpenAI、Anthropic、Google 等）都提供 API 接口，但普通用户用起来有很多痛点：需要海外信用卡支付、网络不通、多家 API 格式不统一、没有统一的管理面板……中转站就是帮你把这些麻烦全部解决——你只需要一个统一的 API Key 和一个地址，就能调用全网所有大模型。

**商业模式非常直白**：

```
你以批发价从上游（OpenAI/DeepSeek/通义千问等）买入 Token
  ↓ 加价（通常 1.2-2 倍）
以零售价卖给下游（开发者、小型 AI 应用、个人用户）
  ↓
赚取中间差价
```

这门生意的核心逻辑和「话费充值代理」「流量包分销」一样：**批量买入、零散卖出、赚差价**。区别在于 AI Token 的利润空间更大——因为很多国产模型有免费额度或极低价格，而海外模型在国内有信息差和支付壁垒。

### 1.2 适合人群

| 阶段 | 时间 | 月收入 | 说明 |
|------|------|--------|------|
| 冷启动期 | 1-2 个月 | 0-500 元 | 刚上线，靠朋友圈和小范围推广 |
| 增长期 | 3-6 个月 | 1000-5000 元 | 积累了一批稳定用户，口碑传播 |
| 稳定期 | 6 个月+ | 3000-20000 元 | 取决于用户规模和留存率 |

> ⚠️ 收益与用户量直接挂钩。一个 50 人的稳定用户群，月利润大约 2000-5000 元；200 人以上可过万。但获客是最大挑战。

### 1.6 入门教程：从零到上线

> 如果只需要服务国内用户（调用国产模型），选国内云服务器；如果需要代理 OpenAI/Claude，选海外服务器。

#### 第 2 步：配置服务器环境

```bash
# 1. 安装 Docker（Ubuntu/Debian）
curl -fsSL https://get.docker.com | bash

# 2. 启动 Docker 服务
systemctl start docker
systemctl enable docker

# 3. 验证安装
docker --version
```

#### 第 3 步：部署 New API

```bash
# 1. 拉取并启动
docker run --name new-api -d --restart always \
  -p 3000:3000 -e TZ=Asia/Shanghai \
  -v /home/ubuntu/data/new-api:/data \
  calciumion/new-api:latest

# 2. 验证运行状态
docker ps | grep new-api

# 3. 访问管理面板
# 浏览器打开 http://你的服务器IP:3000
# 默认账号: root  密码: 123456
# ⚠️ 登录后立即修改密码！
```

#### 第 4 步：申请上游 API Key

| 模型提供商 | 注册地址 | 免费额度 | 推荐指数 |
|-----------|---------|---------|---------|
| DeepSeek | https://platform.deepseek.com | 有免费赠送 | ⭐⭐⭐⭐⭐ |
| 通义千问 | https://dashscope.aliyun.com | 有免费额度 | ⭐⭐⭐⭐⭐ |
| 智谱 GLM | https://open.bigmodel.cn | 有免费额度 | ⭐⭐⭐⭐ |
| 百度文心 | https://cloud.baidu.com/product/wenxinworkshop | 有免费额度 | ⭐⭐⭐⭐ |
| 讯飞星火 | https://xinghuo.xfyun.cn | 有免费额度 | ⭐⭐⭐ |

> **策略建议**：先接入免费额度的国产模型，零成本启动。等有用户了再接 OpenAI 等付费模型。

#### 第 5 步：在 New API 中添加渠道

1. 登录管理面板 → 渠道管理 → 添加新渠道
2. 选择模型提供商类型（如 DeepSeek）
3. 填入上游 API Key
4. 选择支持的模型
5. 设置倍率（建议 1.2-1.5 倍，即加价 20%-50%）
6. 点击测试，确认渠道可用

#### 第 6 步：配置域名和 HTTPS

```bash
# 1. 安装 Nginx
apt install -y nginx

# 2. 配置反向代理
cat > /etc/nginx/sites-enabled/api.yourdomain.com << 'EOF'
server {
    server_name api.yourdomain.com;
    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_read_timeout 300s;
    }
}
EOF

# 3. 申请 SSL 证书（免费）
apt install -y certbot python3-certbot-nginx
certbot --nginx -d api.yourdomain.com

# 4. 重启 Nginx
systemctl restart nginx
```

#### 第 7 步：正式上线运营

- 在「令牌管理」中创建面向用户的 API Key
- 在「运营设置」中配置充值链接（如需在线支付）
- 在「公告管理」中发布上线公告
- 开始推广：朋友圈、技术群、论坛、公众号

### 1.7 风险提示

| 风险类型 | 说明 | 应对措施 |
|---------|------|---------|
| **法律合规** | 《生成式人工智能服务管理暂行办法》要求对公众提供 AI 服务需备案 | 仅面向开发者提供 API 转发，不直接面向终端用户提供对话服务；或完成相关备案 |
| **上游封号** | 滥用免费额度可能被上游封禁账号 | 合规使用，不批量注册薅羊毛 |

| **资金安全** | 用户充值后跑路风险（行业乱象） | 做长期生意，不卷款；提供透明计费 |
| **技术运维** | 服务器宕机、上游 API 变更 | 设置监控告警，及时跟进上游变更 |

## 二、AI 博主 / 自媒体创作者（必选）

### 2.1 项目简介

AI 博主就是**围绕 AI 主题做内容创作，通过流量和影响力变现**。

这不是让你去当程序员。恰恰相反——AI 博主的核心竞争力不是技术，而是**把 AI 讲明白、讲有趣、讲有用**的能力。技术大神往往讲不好科普，而普通人反而更能理解普通人的痛点。

### 2.2 适合人群

| 维度 | 要求 |
|------|------|
| 技术背景 | ❌ 完全不需要 |
| 启动资金 | 0-500 元（一部手机 + 剪映即可） |
| 时间投入 | 每天 2-3 小时（下班后兼职即可） |
| 核心能力 | 选题敏感度、文案能力、视频剪辑、镜头表现力 |

### 2.3 为什么普通人适合做 AI 博主

#### 理由一：无需技术背景

很多人以为做 AI 博主需要会编程、懂数据结构、懂机器学习。**完全不是**。

读者/观众关心的是：

- 这个 AI 工具怎么用？（操作步骤，不是原理）
- 能帮我解决什么问题？（场景，不是算法）
- 值不值得花钱？（体验，不是跑分）

技术大牛讲 AI，容易陷入「原理焦虑」——总想讲清楚 Transformer 架构、Attention 机制。但普通用户根本不关心这些，他们只想知道「这东西能不能帮我写周报」「能不能帮我做 PPT」。

**你作为普通人的优势**：你比技术大牛更懂普通人的需求和痛点。你知道读者在哪里卡住、在哪里困惑、在哪里想放弃。这种共情能力，是技术背景无法替代的。

#### 理由二：内容创作能力才是关键竞争力

AI 博主的核心竞争力是这四项：

| 能力 | 权重 | 说明 |
|------|------|------|
| **选题敏感度** | 30% | 能在 AI 热点爆发后 2 小时内出选题；知道什么内容有人搜、有人看、有人转发 |
| **文案能力** | 25% | 能把 AI 工具的使用过程写成/讲成普通人能听懂的大白话 |
| **视频剪辑** | 25% | 会用剪映做基本剪辑、加字幕、加特效、控制节奏 |
| **镜头表现力** | 20% | 出镜时的自然度、感染力、情绪表达（不出镜做纯图文也行，但视频流量更大） |

**注意**：这四项能力没有一项需要编程。颜值、声音、表现力这些「人的特质」，反而是 AI 替代不了的。

#### 理由三：三方共赢生态

AI 博主处在一个健康的三方共赢生态中：

```
AI 厂商（OpenAI、DeepSeek、通义千问、智谱……）
  ↓ 需要：曝光、用户增长、产品测评
  ↓ 提供：免费 API 额度、赞助费、佣金分成、内测资格
  ↓
AI 博主（你）
  ↓ 需要：内容素材、变现渠道、流量扶持
  ↓ 获得：广告收入、课程销售、佣金、付费社群
  ↓
自媒体平台（公众号、抖音、小红书、B站……）
  ↓ 需要：优质内容、活跃用户、广告库存
  ↓ 提供：流量分成、创作激励、平台资源位
  ↓
读者/观众
  ↓ 获得：有价值的 AI 知识、工具推荐、避坑指南
```

这个生态里每一方都在贡献价值，每一方都在获得回报。AI 厂商有营销预算、平台有流量分成、读者有信息需求，博主就是连接三方的桥梁。

**实际案例**：一个 5 万粉的 AI 博主，月收入构成大约是——平台广告分成 2000-5000 元 + AI 工具推广佣金 3000-8000 元 + 知识付费课程 2000-10000 元 = 7000-23000 元/月。

### 2.6 入门教程

#### 第 1 步：账号定位

| 定位方向 | 内容类型 | 适合平台 | 示例 |
|---------|---------|---------|------|
| AI 工具评测 | 测评各种 AI 工具，帮用户避坑 | 公众号 + 小红书 | 「这个 AI 工具值不值得买」 |
| AI 热点解读 | 把 AI 新闻翻译成大白话 | 公众号 + 抖音 | 「OpenAI 又发新模型了，对你有什么影响」 |
| AI 教程 | 手把手教普通人用 AI | B站 + 小红书 | 「3 步用 AI 做出专业 PPT」 |
| AI 副业 | 分享用 AI 赚钱的方法 | 公众号 + 抖音 | 「用 AI 帮人写简历，月入 3000」 |

> **定位建议**：选一个你最有感觉的方向，坚持 3 个月再考虑调整。不要今天写工具评测、明天做热点解读——算法和读者都喜欢稳定。

#### 第 2 步：内容选题方向

**选题的 5 个来源**：

1. **AI 热点**：用 aihot skill 或关注 AI 资讯号，第一时间跟进热点
2. **读者提问**：评论区、私信里高频出现的问题就是选题
3. **工具更新**：AI 工具发新版、新增功能时，第一时间出教程
4. **亲身踩坑**：你自己用 AI 时遇到的问题和解决方案
