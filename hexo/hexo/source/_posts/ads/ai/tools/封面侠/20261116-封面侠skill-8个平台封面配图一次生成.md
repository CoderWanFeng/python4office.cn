> **一句话总结**：同一篇文章要发公众号、小红书、抖音、知乎、B 站、微博……比例全不一样，封面得重做 6 遍——这个 Skill 一次给你全出齐。

大家好，我是程序员晚枫。

先说个我自己的痛点。

一篇长文写完，接下来是分发：公众号发一遍、小红书发一遍、抖音发一遍、知乎改改再发一遍、B 站也得放一张封面。

**然后你发现每张封面的比例都不一样：**

| 平台 | 比例 |
|---|---|
| 公众号 | 2.35:1 |
| 小红书 | 3:4 或 9:16 |
| 抖音 | 9:16 或 16:9 |
| 知乎 | 16:9 或 4:3 |
| B 站 | 16:10 |
| 微博 | 5:4 或 16:9 |
| OG Card | 1.91:1 |
| Twitter Card | 2:1 |

8 个平台，**横版竖版高反差戏剧三种风格全都不一样**。手动做？改一次字号要同步改 8 个地方，改到第三个就开始想砸键盘。

所以我写了「封面侠（cover-hero）」：**一个文章，8 个平台的封面和配图，一次出齐。**

**SkillHub 发布页**：[封面侠：https://skillhub.cn/skills/user_bf8c5b73/wanfeng-cover-hero](https://skillhub.cn/skills/user_bf8c5b73/wanfeng-cover-hero)

## 一、它走的路：手写 HTML + 浏览器渲染

先说清楚技术路线，因为这个选择决定了它的上限。

**它不调 AI 生图。**

你要是用 AI 生图做封面，好看是真好看，但**它没法保证你的标题字一个不错、比例一分不差、元素不多不少**。生图工具给的是「一张好看的图」，不是「一张能用的封面」。

封面侠的路子是：

```
手写 HTML（模板 + 注入内容）
  → Puppeteer 无头浏览器截图
  → 得到像素级准确的 PNG
```

**HTML 里的每一个字、每一个间距、每一个阴影，都是可以用代码算的。** 这也是它能做到「渲染完自动自检」的前提。

视觉风格不是自己发明的，而是用了一套现成的视觉体系：**HyperFrames 风格**——米白底 + 圆点纹理、黑顶栏、橙绿强调色、卡片带偏移黑阴影。

## 二、整个过程是 5 步对话

它的交互设计有个原则我很喜欢：**先要内容，再问平台。**

因为如果一上来就问「你要发到哪些平台」，用户会懵；但如果先说「这篇文章讲什么」，那就简单多了。

**第 1 步：给内容。** 它问你四件事：

```
1. 文章主题（一句话）
2. 主要观点（2-3 句）
3. 提到了哪些名人 / 大公司 / 工具
4. 文章类型：横评 / 教程 / 故事 / 决策 / 对比
```

**第 2 步：提炼「视觉锤」（这一步它自己干，不用你答）。**

视觉锤就是封面上一眼能记住的那个东西。比如：

- 横评类 → **一个大数字「5」**
- 教程类 → 一个具体的工具名或图标
- 故事类 → 一个强对比的意象

它还会顺手把「技术词翻译成人话」：比如「Codex 视频插件」→ 封面写「**AI 拍视频的工具**」。

**因为封面不是给同行的，是给刷到的人的。**

**第 3 步：选平台（可多选）。** 8 个平台勾选。建议一次不超过 3 个——**平台越多，迭代越乱**。

**第 4 步：选风格档位。**

| 档位 | 什么时候用 |
|---|---|
| default（默认） | 完整 HyperFrames 视觉，通用 |
| compact | 信息密度更高，教程、卡片多的场景 |
| bold | 更吸睛，封面、故事场景 |

**注意：三个档位都是 HyperFrames 的，不换风格，只调字号、间距、元素个数、装饰强度。**

**第 5 步：选产物类型。** 每个平台的默认清单都定好了，比如公众号是「1 张封面 + 0~7 张配图（按文章长度）」，小红书是「1 张笔记封面 + 0~5 张内页图」。

## 三、三个命令，从手改到全自动

### 方式一：一次跑几个平台

```bash
node assets/code/src/pick-template.js \
  --platform wechat,xhs,douyin \
  --type cover \
  --output task/foo/imgs/
```

### 方式二：一键全 8 平台（v5.3）

```bash
node assets/code/src/pick-template.js --all-platforms --output task/foo/imgs/
```

跑完目录自动长这样：

```
task/foo/imgs/
├── wechat/     cover-v1.html + cover-v1.png
├── xhs/        cover-v1.html + cover-v1.png
├── douyin/     cover-v1.html + cover-v1.png
├── zhihu/      cover-v1.html + cover-v1.png
├── bilibili/   cover-v1.html + cover-v1.png
├── weibo/      cover-v1.html + cover-v1.png
├── og/         cover-v1.html + cover-v1.png
└── twitter/    cover-v1.html + cover-v1.png
```

**`--output` 后面带斜杠或不带 .html 后缀，就自动按平台分目录；带 .html 就当单文件输出。** 这个设计挺贴心，不用自己去建目录。

### 方式三：直接从文章里读（推荐）

v5.4 之后，**你连 HTML 都不用手改**。在 MD 头部写清楚要什么，它自动注入：

```yaml
---
type: tutorial
platform: wechat xhs douyin
kicker: 6 个 <em>AI Skill</em>
hammer: 6 合一
sub: <span class="hl">6 合一</span>·1 仓库<br/>让 AI 干活
cards:
  - name: aihot-topic
    role: 热点选题
    step: SKILL 01
  - name: cover-hero
    role: 封面 + 配图
    step: SKILL 03
    pick: true          # 这张高亮成绿色
---
```

```bash
node assets/code/src/pick-template.js --article task/foo/foo.md --all-platforms --output task/foo/imgs/
```

还能直接在命令行给：

```bash
node assets/code/src/pick-template.js --platform xhs \
  --kicker "6 个 <em>AI Skill</em>" --hammer "6 合一" \
  --sub 'AI 从<span class="hl">噪声</span>中<br/>长出合影' \
  --output task/foo/imgs/
```

**注入字段就四个：** kicker（顶标小字）、hammer（视觉锤大字）、sub（主副标）、cards（卡片数组）。没给的字段保留模板原样。

## 四、渲染完自动自检，这是我最值钱的一点

```bash
cd task/foo/imgs/
for f in *.html; do
  node assets/code/src/render-cover.js "$f"
done
```

跑完会自动打印一份自检报告：

```
✓ 尺寸 2160 × 2880（小红书 3:4，2× DPI）
✓ 主标 14 字（≤20 字限制内）
✓ 文件大小 1.2 MB（≤2 MB）
✓ 安全区无溢出
✓ 3 张卡片（1-5 合理区间）
```

**为什么要自动自检？** 因为封面这东西，**你是坐在电脑前看的，读者是在手机上看的**。

大标题在电脑上看着刚好，在手机上就糊了；小字在电脑上看得清，在信息流缩略图里就是一团糊。**这些问题用眼睛看是看不出来的，只能用规则算。**

它自动查的五项：尺寸对不对、主标字数超没超平台限制、文件多大、有没有溢出安全区、卡片数量合不合理。

## 五、几个平台的脾气不一样

它给每个平台准备了不同的适配层，不是同一张图拉伸：

| 平台 | 适配模式 | 特点 |
|---|---|---|
| 小红书 | 高反差 | 底色更跳、主标 ≤20 字（信息流缩略图小） |
| 抖音 | 戏剧 | 顶栏更高、主标 **≤8 字**（3 秒法则，竖屏） |
| 公众号 / 知乎 / B站 / 微博 / OG / Twitter | 标准 | 常规排版，文字必须落在中央安全区 |

**抖音那条 ≤8 字，我一开始觉得太狠了，试完发现是对的。** 抖音信息流里，封面上的字超过 8 个基本没人读完——**不是排版问题，是用户根本没时间看。**

## 六、四条硬性约束，不可妥协

1. **名人 / 大公司必须出现** —— 文章里提到 Sam Altman，封面就得有他。不出现就是信息缺失。
2. **文字必须小学生能秒懂** —— 封面不是摘要，是钩子。
3. **图标必须一眼可识别** —— 不用抽象几何，不用 AI 插画风。
4. **元素 ≤ 5 个** —— 视觉锤 + 主标 + 卡片 + 角标 + 脚注，多了就乱。

外加几条视觉 DNA 是锁死的：米白底 `#f3efe6` + 圆点纹理、黑顶栏、橙 `#ff5b1f` / 绿 `#6cd76b` 强调色、卡片偏移黑阴影 `4px 4px 0`（**这是它的标志，不要模糊成柔和阴影**）。

**不要渐变、不要玻璃拟态、不要拿 emoji 当主视觉锤。** 这条视觉体系能成立，靠的就是这些约束。

## 七、迭代节奏

**每轮只改一处。** 字号、间距、配色、文案、图标——一次改一个，改完跑一次渲染看效果，出 `v2`。

不删旧版本，方便回滚。
