> **一句话总结**：免费模型的信息散在几十个平台、还天天变。我做了个 Skill 把它收拢成三类清单——**你只管问，它 3 轮对话内告诉你现在能白嫖什么**。

大家好，我是程序员晚枫。

去年到现在，我在「免费大模型」这个坑里写了不少文章：

**每一篇都是我自己去搜、去抓、去验证的。**

写多了我就发现一件事：**这事最大的成本不是写文章，是"搜"。**

今天用户问「Cursor 里哪个模型不花钱」，明天有人问「DeepSeek 现在还免费吗」，后天又有人问「有没有不用注册就能用的」。

**同一个问题，答案隔一个月就可能变。**

所以我把这套「搜 + 验证 + 归档」的流程固化成了一个 Skill：**免费大模型查找器（free-ai-models）**。

## 一、它先解决一个最烦的事：你到底要哪类「免费」

我发现大部分人问「有没有免费的大模型」，其实是**三种完全不同的需求**混在一起问的。

| 类别 | 你真正想要的是 | 典型问法 |
|---|---|---|
| **① 直接免费用** | 打开网页就能聊，不用写代码 | "现在哪个 GPT 是免费的""有没有免登录的" |
| **② 软件里免费切换** | 在 Cursor / Cline 里选模型 | "Cursor 里哪个模型免费""Cline 接哪个 API 不花钱" |
| **③ 平台免费额度** | 拿 API Key 自己调 | "Gemini API 免费额度多少""DeepSeek 有免费 token 吗" |

**这三类的答案完全不重叠。**

一个人说「我想用 GPT」，可能是想上网站聊天，也可能是想接进 Cursor 写代码，还可能是想拿 Key 跑个脚本。

**如果一上来就甩一长串清单，他大概率要自己再筛一遍。**

所以这个 Skill 的第一个动作，是**在第 1 轮就锁定类别**。

它有一张关键词路由表：

| 你输入里出现 | 直接锁定 |
|---|---|
| 网站 / 网页版 / 在线用 / 免登录 / App | ① 直接免费用 |
| Cursor / Cline / Cherry Studio / VS Code / 软件里 | ② 软件里切换 |
| API / token / 额度 / 配额 / key | ③ 平台额度 |

**实在模糊，它也只问你一次。** 不来回拉扯。

## 二、本地优先：不联网也能秒答

这是我觉得设计得最对的一点。

它不是每次都去网上抓。**本地存着一份快照**，`reference/` 目录下三个文件：

```
reference/
├── direct-free.md      # ① 直接免费用
├── in-software.md      # ② 软件里免费切换
└── platform-quota.md   # ③ 平台免费额度
```

**本地有的，3 秒内给答案。**

为什么非要本地优先？因为这类问题**绝大多数是重复的**——每天被问来问去就那几个模型。每次都联网去抓官网，既慢，又容易抓到一个带广告的页面，还得自己再判断一遍。

**本地优先 + 联网兜底**，这四个字是整个 Skill 的骨架。

## 三、什么时候它才联网

本地快照会过期，所以它定了一条硬规则：**快照超过 30 天，必须重抓。**

触发联网的四种情况：

1. **本地没有** —— 你问的模型/平台它压根没收录；
2. **快照过期** —— 距离数据日期超过 30 天；
3. **你质疑** —— "现在还免费吗""额度变了吗"；
4. **活动到期** —— 快照里的活动截止时间已经过了。

联网时它只干一件事：**抓官方页，把结论写回本地**。

```
抓到官方页确认仍免费 → 更新本地条目的数据日期
抓到已取消/变更     → 改条目，并标「⚠️ 活动已结束」
抓到全新发现        → 新增条目，注明来源 URL + 抓取日期
```

**然后它会顺口说一句：**

> "刚才查了下官方页，结论是这样。已经更新本地数据了，下次不会再问。"

**这一点我特别满意——它不是一次性查询工具，它是个会自我维护的数据库。**

而且它有几条"不抓"的原则，我觉得比"抓"更重要：

- **不抓论坛、Reddit、知乎** —— 噪音大、可信度低；
- **不抓非官方汇总站** —— 避免二手数据污染本地；
- **不抓需要登录的页面** —— 抓不到，硬抓只会拿到一个登录墙。

**二手信息污染一手数据，是这类工具最容易犯的错。** 它从根上堵掉了。

## 五、它最有价值的一个细节：所有时间敏感字段都标日期

这是我最想单独拿出来讲的一点。

免费额度这件事，**会变的**。活动会结束，限额会调整，某天还会突然取消。

所以它的硬规则里有一条：**所有"免费额度 / 活动 / 截止时间"都必须标数据日期。**

你看上面那三张表，每张表头上都写着：

> 数据基准日：2026-07-12 / 2026-07-16

**这不是装饰，是免责声明，也是承诺。**

它等于在说：**"我现在给你的这些，是 7 月 12 号那天的真实情况。过了 30 天我再去查。"**

**一个会过期的东西，不标日期就是在骗人。**

我写「免费大模型系列」这几十篇文章的时候，每篇都在跟这个问题较劲——文章发出去半年后，读者照着做发现额度早没了。**从那以后我就养成了习惯：凡是写额度，必须带日期。**

这个 Skill 把这个习惯变成了默认行为。

## 六、它明确不做什么

这类工具最容易被做成"什么都帮你干"，然后在合规上翻车。它的边界写得很死：

| 行为 | 做不做 | 说明 |
|---|---|---|
| 给"现在能免费用"的清单 | ✅ | 核心功能 |
| 帮你注册账号 | ❌ | 引导你自己去官网 |
| 帮你填信用卡领试用 | ❌ | 涉及付费与合规风险 |
| 帮你绕过付费墙 | ❌ | **坚决不教** |
| 推荐付费训练营 / 课程 | ❌ | 不引流 |
| 在本地记录"薅羊毛技巧" | ❌ | 只记"官方提供"的部分 |
| 抓官方页 | ✅ | 仅官方源，且更新本地 |
| 生成 Markdown 清单 | ✅ | 你主动要才生成 |

**"只记官方提供的部分"这条特别关键。**

市面上很多"免费攻略"其实是把各种漏洞、共享账号、破解方案混在一起推销。**那些东西一封号就废，还可能违规。**

它只做一件事：**告诉你官方现在给了什么免费额度，怎么正常领。**

## 七、它还能给你出一份清单

你说一句"帮我整理成文档"，它会在本地生成一份带 front matter 的 Markdown 报告：

```
free-ai-models/task/20261116-国内免费模型/免费大模型清单.md
```

文件骨架是固定的：

```markdown
---
title: 免费大模型清单 · 2026-11-16
data_date: 2026-07-16   # 数据基准日
---

# 免费大模型清单 · {你的关键词}

> 数据基准：2026-07-16（活动/额度可能随时变化）

## ① 直接免费用
## ② 软件里免费切换
## ③ 平台免费额度

## 来源
- 本地数据：reference/direct-free.md 等
- WebFetch 兜底：{URL}（抓取于 YYYY-MM-DD）
```

**末尾有"来源"这一节。**

一份免费额度清单，最怕的就是"网上抄的，不知道哪来的"。**把来源和抓取日期写进文档，这份清单才能被复查、被追溯、被更新。**

## 八、怎么用

直接说就行，不需要记命令：

> **@免费大模型查找器** 我想在 Cursor 里写代码，有没有不花钱的模型？

> **@免费大模型查找器** 现在还有哪些不用注册就能用的？

> **@免费大模型查找器** DeepSeek 现在还免费吗？给我个准话。

第三种问法它会答成：

> **Yes/No + 来源 + 数据日期**，然后主动追一句："要不要我把所有平台再列一遍对比一下？"

**它还会按你的场景给推荐。** 你说"我要写代码 / 做 PPT / 翻译"，它会给表格加一列"擅长"，然后挑 2–3 个最匹配的。

**不给你塞一堆，自己挑。**
