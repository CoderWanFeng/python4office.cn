大家好，我是程序员晚枫。

上一条视频我还在喊"来不及解释了赶紧去领"，那条 5 亿的额度，10 月 26 日早上 9 点准时清零，不少人跑来问我"还有没有下一波"。

有了，而且更狠。

10 月 27 日，智谱 ZCode 官方宣布：**每人每天免费送 3 亿（300,000,000）GLM-5.3-Flash Token。**

注意三个关键词：**每人、每天、免费**。

领一个月就是 90 亿——比 1024 那次的 5 亿，多出整整 18 倍。

## 一、规则速览：三个时间点记住就行


| 项目         | 规则                                                  |
| -------------- | ------------------------------------------------------- |
| **额度**     | 每人每天 **3 亿 Token**                               |
| **模型**     | **仅限 GLM-5.3-Flash**（选旗舰 GLM-5.3 照样扣你的钱） |
| **领取时间** | 每天 **19:00**（北京时间）起，客户端内领取            |
| **使用窗口** | 当晚 **23:00 → 次日 09:00**，共 10 小时              |
| **过期规则** | 次日 09:00 清零作废，**不累积**，第二天重新领         |
| **费用**     | 全免，不消耗任何付费套餐额度                          |
| **截止日期** | **官方没说**——活动办多久不知道                      |

官方公告用的是 UTC 时间（领取 11:00 UTC 起、使用 15:00–次日 01:00 UTC），换算成北京时间就是上表这几点，别算错时区。

![ZCode 官方公告：300M Tokens every day](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/zcode-3yi-official.png)

这个作息说实话有点阴间：**晚上 7 点抢鸡蛋，晚上 11 点开工，早上 9 点收工。**

但换个角度想——23:00 到 09:00 正好覆盖整段睡眠时间，设计意图非常直白：**睡前把活派出去，早上起来看结果。**

## 二、三步领到手，第三步最容易漏

**第一步：更新客户端**
把 ZCode 升到最新版（官网当前 **v3.16.3**）。官方明确提醒：**3.10 以下的老版本根本没有活动入口**，装完记得重启一次。官网 zcode.z.ai，Mac / Windows / Linux 都有包。

> 补充一句：**国内账号从 BigModel 登录，海外账号从 Z.ai 登录，入口是一样的**——不用折腾切国际版。

**第二步：19:00 后点左下角的活动卡片**

![客户端左下角就是每日 3 亿的领取入口](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/zcode-3yi-entry.png)

卡片没弹出来？先完全退出客户端再重启；还不行就检查版本号。

**第三步：切通道、选模型——这步漏了等于白领**

领完必须做两件事：

1. 把使用通道切到 **Global Building**
2. 把模型选成 **GLM-5.3-Flash**（模型选择器在对话框的模型名称处）

![领完要去设置 → 模型设置 → Start Plan 里确认激活](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/zcode-3yi-activate.png)

我第一次用也栽在这儿：白天在软件里找了半天没找到入口，晚上 7 点它自己冒出来了；领完之后又发现跑起来还是在扣自己的额度——**因为模型还停在原来那个上。**

领完可以顺手到 Settings → Usage stats 里确认计量是不是停了。

![领取成功：3 亿 Tokens，23:00 生效，次日 09:00 到期](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/zcode-3yi-claimed.png)

## 三、3 亿到底能干多少活？

先看官方演示：一个五子棋项目，五步走完（含启发式 AI 落子、移动端适配），**总共只花了 89K Token**。

一次中型代码改动（读代码、改代码、跑测试）通常落在**几十万 Token** 量级。

按这个算，3 亿够你跑上千次中型任务。有博主实测一晚烧掉 **2.2 亿**（56 轮消息）——**一整晚高强度跑，都没跑完当天的额度。**

按官网定价粗算这笔账也不亏：GLM-5.3-Flash 输入 0.8 元/百万、输出 2.8 元/百万，3 亿就是 300 个百万——**全按输入约 240 元，全按输出约 840 元，典型用法一天大约 300 元。**

连领一个月，就是小一万块的调用量。

所以结论很明确：**额度不是瓶颈，时间窗口才是。** 瓶颈是你有没有活派给它。

## 四、为什么智谱突然这么大方？

讲个前情，你就全明白了。

**9 月中旬，ZCode 出过一次事**:有开发者发现自己电脑里躺着一个 313MB 的加密压缩包——ZCode 的"仓库索引"功能默认开启，把整个工作区（含 .git 历史、配置文件、甚至数据库口令）打包准备上传云端，而且重试了 564 次。

事件发酵一周，智谱当天致歉，随后开源代码库、删除云端数据（第三方核查确认）、上线"零数据留存"，并在 9 月 28 日发了一份名叫 **Trust.patch** 的补偿方案——免费 Token 就是其中一部分。

然后你再看这条时间线：


| 时间              | 额度                         |
| ------------------- | ------------------------------ |
| 8 月底            | 周末限定 3 亿（每周一次）    |
| 9 月 28 日        | Trust.patch：1 亿 × 10 万份 |
| 10 月 10 日       | 周末 3 亿                    |
| 10 月 23 日       | 1024 程序员节：5 亿          |
| **10 月 27 日起** | **每天 3 亿，常态化**        |

看出来了吗？**从"补偿"到"日常"，智谱在用免费额度把用户一点点请回来。**

信任这东西，破坏只要一天，重建要一月一月地攒。发 Token 是成本最低、见效最快的一种道歉方式——而且用户还乐意。

顺带说个行业背景：今年公开致歉并补偿的大模型厂商已经有好几家（DeepSeek 10 月故障全额返还、Kimi K3.1 限流补偿 25% 额度）。**AI 从"能用"走向"敢用"，信任成本正在变成最贵的一笔账。**

## 五、四个坑，踩一个都心疼

1. **19:00 领 ≠ 19:00 能用**。中间空 4 小时，19 点领完发现跑不动不是 Bug，等到 23 点
2. **只免 Flash，不免旗舰**。手滑选了 GLM-5.3，照常扣你的套餐额度
3. **额度出不了客户端**。只能在 ZCode 里用，不能导出 API Key，也接不进 Cursor、Claude Code 这类工具；并发上限 3 个任务
4. **高峰期会限速和掉线**。社区反馈周末深夜有 Reconnecting、任务中断，付费用户也中招。**重要改动先在 Git 上留好分支**，崩了能重来

另外别混了：新用户连 BigModel 后，头 5 天每天还有 **GLM-5.3 300 万 + Flash 500 万**的体验额度，那是另一套，和每日 3 亿互不相干。

## 六、10 小时怎么用最值？

按"不需要人盯着"来派活：

- **白天**：把要做什么想清楚——批量重构、补单测、补文档、梳理老项目依赖、做个小工具
- **23:00 后**：需求完整丢进去，让它熬夜跑
- **早上**：看 diff、看测试通过率，顺手检查有没有改了不该改的地方

选活标准只有一条：**方向已经明确的活才派。** 探索性的任务别丢进去，跑一夜出一堆看不上的东西，比不用还亏。

还有个小技巧：GLM-5.3-Flash 支持图像输入，**把界面截图丢进去让它还原布局**，比纯文字描述靠谱得多。
