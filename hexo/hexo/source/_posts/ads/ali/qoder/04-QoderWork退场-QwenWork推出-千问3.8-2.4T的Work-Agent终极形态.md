# QoderWork 退场，QwenWork 推出：千问 3.8 撑起的新一代企业生产力

兄弟们，今天又是一个大新闻。

**QoderWork 这个名字，以后基本看不到了。**

取而代之的，是**QwenWork**——千问家族的 Work Agent 产品。

事情大致是这样的：

- 阿里先把 AI Coding 的市场份额拿到了接近 **50%**
- 然后在 7 月 19 日，发布了 **2.4T 参数的千问 3.8-Max**（预览版，"按天进化"模式）
- 同时宣布：**QoderWork 退场，QwenWork 接管 Work Agent 这条线**
- QwenWork 整合了「**悟空**」的多 Agent 协同能力 + 「**MuleRun**」的桌面/跨系统操作能力
- 定位升级：从"AI 写代码" → "**AI 干企业里所有的活**"

一句话总结这次升级：

> **千问补上了最后一块短板——Work Agent。**

下面我把这件事拆开讲。

---

## 一、先说说背景：千问这两年到底做了什么？

阿里通义千问这 2 年的 AI 布局，我做了个时间线——

| 时间 | 事件 |
|------|------|
| 2024 年 | 千问 2 系列，定位通用对话 |
| 2025 年 | 千问 3 系列，引入 Agent 能力 |
| 2026 年 2 月 | 千问 3.5-Plus，397B 参数 |
| 2026 年 5 月 | 千问 3.7-Max，约 1T 参数 |
| 2026 年 7 月 19 日 | **千问 3.8-Max 预览版**，**2.4T 参数**，日更模式 |
| 2026 年 7 月 | **QoderWork 退场，QwenWork 推出** |

你能看出来，**这是一条很清晰的"模型→产品"联动路线**——

模型变强，产品线也跟着重命名+整合。

这次 QoderWork → QwenWork，就是这条路线上的最新一步。

---

## 二、QoderWork 为什么退场？

直接说原因，3 个：

### 1. 名字就尴尬

QoderWork 属于「Qoder 系列」。Qoder 是什么？**写代码的 IDE**。

把"写代码的 IDE"叫 Work Agent——**听着就违和**。

- 用户预期：这是个写代码的工具
- 实际功能：这是个干办公的 Agent

定位错位迟早要出事的。

### 2. 千问模型已经"出师"

QoderWork 早期用的是外部模型（不是自己的千问）。

现在千问 3.8 出来了，**自己的模型能顶上来**——

那产品冠名权自然要回到千问自己。

### 3. Work Agent 这个战场，必须整盘托出

Work Agent 不是单点产品，是一套**生态**——

- 多 Agent 协同
- 桌面/浏览器/Office 跨系统操作
- 企业级权限管控
- 私有化部署能力

这种东西，必须用一个**独立品牌**承载，不能寄生在"IDE 系列"下面。

**所以 QoderWork 退场，QwenWork 推出，是顺理成章。**

---

## 三、QwenWork 是什么？整合了什么？

QwenWork 不是凭空冒出来的。

它是把 **3 个老产品的能力打包重组**，再加上千问 3.8 的模型做底座。

| 来源 | 之前的能力 | 在 QwenWork 中的位置 |
|------|----------|---------------------|
| **QoderWork** | 多 Agent 协同办公 | 核心调度框架 |
| **悟空（阿里自研）** | 多智能体编排 + 任务规划 | 任务分解与协作引擎 |
| **MuleRun** | 桌面 + 浏览器 + Office 跨系统操作 | 执行层（真去操作你的电脑）|
| **千问 3.8-Max** | 2.4T 模型，按天进化 | 大脑 |

所以 QwenWork 的产品结构是这样的：

```
QwenWork（统一品牌）
   ├── 大脑层：千问 3.8-Max（2.4T，按天进化）
   ├── 调度层：悟空（多 Agent 编排）
   ├── 执行层：MuleRun（桌面 / 浏览器 / Office）
   └── 应用层：Office 全家桶（Word / Excel / PPT / 邮件）
```

这套架构，听起来是不是很熟悉？

对——和豆包 6 月 24 日发布的「**办公任务 Agent**」、和 Claude Code 的「**Skills + Claude Tag 异步协作**」，都是**同一个思路**：

> **大模型（大脑）+ Agent 框架（调度）+ 桌面/浏览器能力（执行）**

这已经不是某家的"特色"，而是**桌面 Agent 的标准架构**。

千问这次入场，等于宣布：**阿里在这个战场上正式上桌。**

---

## 四、为什么 Work Agent 这么重要？

你可能想问：Work Agent 凭什么值这么多功夫？

我给你 3 个数字：

| 数字 | 来源 | 含义 |
|------|------|------|
| **95%** | 斯坦福 2026 年 4 月报告 | 企业 AI 项目失败率 |
| **44.4%** | 阿里官方数据 | 千问 3.8 相对 Qwen3.7 在"协同办公"场景的提升 |
| **22.8%** | 阿里官方数据 | 千问 3.8 相对 Qwen3.7 在"代码工程"场景的提升 |

这 3 个数字放在一起，说明什么？

- 企业 AI 项目失败率高，是因为"组织"+"工具"+"数据"不配套
- 真正能跑通的场景，**Work Agent 是核心**——因为它直接接管人的工作流
- 千问 3.8 重点提升了 22.8% 的代码能力 + 44.4% 的办公能力——**两条腿都升级**

> **Work Agent 是 AI 落地的最后一公里。**

谁能搞定，谁就吃掉企业市场最大的蛋糕。

## 五、QwenWork 的 4 个核心能力

基于整合的 3 个老产品 + 千问 3.8 模型，QwenWork 现在的 4 大能力：

### 1. 真正的"多 Agent 协同"

不是一个 AI 干所有事，是**一群 AI 分工合作**——

- 1 个负责拆任务
- 1 个负责查资料
- 1 个负责写文档
- 1 个负责校对
- ……

### 2. 跨系统操作（桌面 + 浏览器 + Office）

这是 MuleRun 能力的延续——

> **AI 不是"告诉你怎么做"，是"直接帮你做完"**

- 帮你打开 Excel
- 帮你填表
- 帮你发邮件
- 帮你做 PPT

### 3. 企业级权限管控

Work Agent 不能只服务个人，必须能**服务企业**——

- 角色权限
- 数据脱敏
- 操作审计
- 私有化部署

千问作为阿里系产品，这套东西是**天然优势**。

### 4. "按天进化"的能力

千问 3.8 是预览版"按天进化"——

> **用户今天用和明天用，背后模型可能已经升级了**

这是 QwenWork 区别于其他 Work Agent 的**最大杀手锏**——

别人模型半年更新一次，QwenWork 用户每天都在用"昨天才训练完的新模型"。

## 六、谁会受到冲击？

QwenWork 推出，对手有 3 类：

| 玩家 | 受冲击程度 | 原因 |
|------|----------|------|
| **豆包办公任务 Agent** | ⭐⭐⭐⭐ | 直接竞品，且豆包桌面端起步晚 |
| **ChatGPT Enterprise / Microsoft Copilot** | ⭐⭐⭐ | 国外方案，国内体验差 |
| **Trae / Cursor / Claude Code** | ⭐⭐ | 主要战场在"写代码"，但 Work Agent 会延伸过来 |
| **传统 RPA 厂商** | ⭐⭐⭐⭐⭐ | Work Agent 直接颠覆传统 RPA 的工作方式 |

**传统 RPA 厂商最危险。**

RPA 是写脚本模拟人操作，Work Agent 是 AI 自主决策——

**后者能用自然语言描述需求，前者必须写代码**。

降维打击。

## 七、3 个你还不知道的细节

### 1. "日更预览版"还在测试

千问 3.8 当前是预览版，**每晚自动迭代**。

好处：能力进化快。
坏处：**生产环境别用**——版本会动，行为可能微妙变化。

### 2. 限时 1 折体验

阿里这次为了抢反馈，Token Plan 个人版限时 **1 折**，夜间 **0.2 折**。

39 元/月的套餐——**相当于 4 块不到**。

### 3. 正式版计划开源

林俊旸离职 140 天后，千问 3.8 正式版将**重回开源路线**。

这意味着：**正式版发布后，本地部署、私有化训练、行业定制都会成为可能**。
