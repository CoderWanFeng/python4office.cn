## 这匹黑马什么来头？

Agnes AI 背后是新加坡的 Sapiens AI 公司，创始团队来自南洋理工、新加坡国立大学。创始人杨通的履历很有意思：新加坡国立大学人工智能方向博士、总统奖学金得主，本科在加州大学伯克利分校读计算机与应用数学，还师从过两位图灵奖得主，此前在微软和领英美国总部任职过。

今年它动作很大：**国内总部刚落地南京江北新区**，研发团队 270 人，硕博占 75%，平均年龄 27 岁。

| 文字 | Agnes-3.0-Flash | 智能指数 36 分，和 DeepSeek V4 Pro 同档 |
| 图片 | Agnes-Image-2.0 | 图像编辑榜 1178 分，紧咬 GPT 和谷歌 |
| 视频 | Agnes-Video-2.5 | 文生视频榜 1082 分，几乎追平可灵 3.0 |

一家公司，三条产品线全都挤进全球前十，这在创业公司里非常罕见。

市场也用脚投票了：开放免费之后，它现在**单周处理的 token 量达到 8.16 万亿**，直接站进全球大模型服务的第一梯队。

## 5 分钟接入：还是熟悉的三件套

老读者应该已经背下来了——注册、拿 Key、填三项。Agnes AI 走的是 OpenAI 兼容接口，流程和之前接 GLM、DeepSeek 一模一样。

**第一步：注册**

打开 platform.agnes-ai.com，注册账号，进控制台建一个 API Key，复制保存。

**第二步：填三项**

以 WorkBuddy 为例，进设置 → 模型 → 添加自定义模型：

| 配置项 | 填什么 |
|---|---|
| API 地址 | `https://apihub.agnes-ai.com/v1` |
| API Key | 上一步生成的那串 |
| 模型名称 | `Agnes-3.0-Flash` |

填完点测试，通了就能在 WorkBuddy 里直接用。Trae、OpenCode 这些工具同理，改 Base URL 就行。

**第三步：试试图片和视频**

这是它和别的免费平台最大的区别。同一个 Key，除了聊天，还能调图像和视频接口：

- 文生图、修图，支持高清输出
- 文生视频、图生视频，**自带同步音频**

以前做一条 AI 视频，订阅费一月几十上百；现在拿免费接口先跑通流程，成本直接归零。对做自媒体的朋友来说，光"视频免费"这一条就值得注册。

举个具体的例子：你要给公众号文章配一条视频号短视频，以前的流程是写脚本 → 找素材 → 剪辑，半天起步。现在用它的接口，文章里的关键句生成画面、图生视频配上动效和同步音频，一条几十秒的视频几分钟出片。质量不敢说吊打专业团队，但**发日常内容绰绰有余，而且你试错的每一秒都是免费的**。

## 为什么它敢全免费？

这里有个值得记住的 AI 知识点：**新玩家冷启动，免费是最好的广告位。**

大模型行业的头部效应极强，一个新模型想被看见，砸钱投流的成本可能比送算力还高。开放免费接口，本质上是一笔划算的交换：

**开发者免费用，平台赚到调用量、真实使用反馈和生态适配**——OpenClaw、Hermes 这些主流 Agent 工具它都主动适配了，图的就是让你用顺手之后离不开。

8.16 万亿的周调用量，就是这份"广告费"的回报。你免费用的是模型，它赚到的是市场卡位——和当年云厂商送服务器额度是一个打法。

看懂了这个逻辑，你还能预测下一波免费红利在哪：**越是急于打开市场的新平台，免费越慷慨**。老牌厂商额度抠搜，新玩家大方送——盯住新发布的产品，你永远是第一批吃到的人。这也是这个系列一直能薅到羊毛的底层原因。

**但有三盆冷水必须泼：**

一，免费细则没有完全公开。官方没写清每日额度上限，只提了每分钟请求数有限制，"永久免费"随时可能调整，**当它是长期饭票之前，先当它是免费试吃**。

二，部分模型还挂着测试版标签，能力会有波动，重要任务记得留一手备份方案。

三，它是海外平台，你的请求会出境。个人学习、公开内容随便用；**公司未公开的资料、涉密数据，别往任何境外接口里传**——这条规矩不针对 Agnes，对所有海外服务都成立。
