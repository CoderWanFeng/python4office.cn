大家好，我是程序员晚枫。

[「免费用大模型」](https://mp.weixin.qq.com/s/bUZUE_6Bb1t-vB3w-ETwxg)这个系列写了二十多篇，有个规律越来越明显：**免费的几乎都是文字模型**。聊天、写代码，送 Token 的平台一抓一大把；可一到图片和视频，要么压根没有免费档，要么额度小得只够试两下。

这其实也好理解。生成一段几秒钟的视频，烧的算力比聊一轮天贵得多，谁送谁心疼。所以想用 AI 做视频的朋友，基本都默认这是一件得花钱的事。

直到我在 Agnes AI 的定价页上，看到视频模型那一栏也写着 0 元。说实话，第一反应是：真的假的？

先简单介绍一下它。Agnes AI 是新加坡 Sapiens AI 公司做的大模型平台，创始团队出自南洋理工和新加坡国立大学，国内总部落在南京江北新区。它不是只做一个聊天模型，而是文本、图片、视频三条产品线一起做，再统一开放成 API，用的是 OpenAI 兼容接口，手里现成的工具基本不用改就能接上。

最近它又往前走了两步：一是上线了一个叫 Pavo 的创作应用，不写代码、手机号登录就能直接出视频；二是把视频模型 Agnes Video 2.5 Flash 的 720P 输出也标成了 0 元。这样一来，会写代码的走 API，不会写代码的走 Pavo，两类人都能免费用上视频模型。

这正是我一直在找的东西。所以这两天我把两条入口都实际走了一遍，官网定价页也逐项对过。这篇就把前因后果讲清楚：它凭什么免费、免费的到底是哪几个模型、两条入口分别怎么进、进去以后怎么用，照着做就能跑通。

---

## 视频这么烧钱，它凭什么敢送

那么问题来了：既然视频最烧钱，一个平台凭什么把文本、图片、视频三条线的体验价都标成 0 元？

答案不复杂：**新玩家冷启动，免费是最好的广告位**。大模型行业头部效应极强，砸钱投流的成本可能比送算力还高；开放免费接口，换来的是调用量、真实反馈和生态适配——下面提到的 8 个现成客户端指南就是证据。

Pavo 这个入口也是同一个思路：API 只能圈住会写代码的人，做一个打开就能用的应用，才能把不会写代码的用户也拉进来。套路和当年云厂商送服务器额度一模一样：**你免费用的是模型，它赚到的是市场卡位**。

对我们的启示很直接：越是急着打开市场的新平台，免费越慷慨。盯住新发布的产品，你永远是第一批吃到的。

## 现在免费的是这 6 个模型

先上清单。官网定价页当前标着 0 元的，一共 6 个 Flash（价格核实于 2026-11-13，以官网当日显示为准）：

| 类型 | 模型 | 能干什么 | 官网当前价格 |
|---|---|---|---|
| 文本 | `agnes-2.5-flash`、`agnes-3.0-flash` | 聊天、看图、写代码、调工具、智能体工作流，上下文 512K | 输入、输出、缓存全部 0 元 |
| 图片 | `agnes-image-2.0 / 2.1 / 2.5-flash` | 文生图、图生图、多图合成、风格迁移，1K 到 4K 四档 | 全部 0 元 |
| 视频 | `agnes-video-2.5-flash` | 文生视频、首尾帧控制、带参考图和参考音频，720P、4–12 秒 | 0 元 |

三条产品线都有免费档，这是它和大多数免费平台最大的区别——别家基本只送文字，它连视频一起送。

三个文本 Flash 里，`agnes-3.0-flash` 是主打的那一个：上下文 512K，最大输出 65,536 Token，三种接口风格都给（OpenAI 的 Chat Completions 和 Responses、Anthropic 的 Messages），接现有工具不用改代码。

## 不写代码：Pavo 入口

这是这次新加的入口。打开 [agnes-ai.cn](https://agnes-ai.cn/)，右上角「登录」下拉里有 Pavo，或者走导航「产品 → AI 原生应用 → Pavo」，地址 [app.pavo-ai.cn](https://app.pavo-ai.cn/)。

![Pavo 首页](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/20261113-agnes-pavo-home.png)

*Pavo 首页的输入框，支持自由组合图、文、视频多元素来创作。*

登录用手机号验证码或微信，不用申请 Key。进去能选剧情短片、Agent、图片生成、视频生成四类。

免费最直接的证据在模型下拉里：`Agnes Video 2.5 Flash` 挂着绿色「免费」「推荐」徽章，而且是**默认选中**——同列表里的 Seedance、Wan 都是限时折扣的付费模型，对比一目了然。

![Pavo 视频模型下拉](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/20261113-agnes-pavo-free-badge.png)

*模型下拉里 Flash 挂着免费和推荐徽章，而且是默认选中项。*

另外说明一句：Pavo 和 API 平台是两套登录体系（手机号 vs 邮箱），想两边都用，就各注册一个。

## 写代码：API 五步走

走 API 的流程还是那五步：

1. 打开 [platform.agnes-ai.cn](https://platform.agnes-ai.cn) 注册登录（邮箱 + 密码）；
2. 控制台创建 API Key；
3. 选模型 `agnes-3.0-flash`（第一次跑通，Flash 就够）；
4. Base URL 填 `https://api.agnes-ai.cn/v1`——**只填到 /v1**；
5. 发一句「你好」测试。

![Agnes 快速开始文档页](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/20261113-agnes-quickstart.jpg)

*快速开始文档页，从注册到发第一次请求的完整步骤都在这一页。*

注意一个地址差异：**官网口径是中国站 `api.agnes-ai.cn`**，网上还流传着海外站 `apihub.agnes-ai.com`。手里配置的是 .com 的，建议按现在的官方文档换成 .cn 重新核一遍。

视频接口和文本不一样，是**异步两步**：先 `POST /v1/videos` 拿到 `video_id`，再每隔 1–2 秒查一次状态，等 `completed` 了从返回的 `url` 字段取视频地址。别像调聊天接口一样傻等返回。

Key 只在创建时显示一次，复制下来自己收好。

## 不想自己配环境：8 个现成客户端

官方为 8 个工具单独写了集成指南：OpenClaw、HermesAgents、Claude CLI、Claude Desktop、WorkBuddy、Cherry Studio、OpenCode、Codex++。填地址和 Key 就能用，不用写胶水代码。

以 Cherry Studio 为例：Add Provider → 类型选 OpenAI → 名称随便填 → Key 填密钥本身 → Base URL 填 `https://api.agnes-ai.cn/v1` → 模型名填 `agnes-2.5-flash`，保存发一句话验证。图片和视频模型要通过 Skills 绑定 `Agnes Image Skill` 和 `Agnes Video Skill`。

官方文档专门列了两个最常见的错：**Base URL 自己接了 `/chat/completions`**（不用，工具会自己拼）、**Key 前面手动加了 `Bearer`**（不要，只填密钥本身）。连不上先查这两处。

![Cherry Studio 官方集成指南页面](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/20261113-agnes-cherrystudio-guide.png)

*Cherry Studio 集成指南里专门标注了密钥不需要手动添加 Bearer 前缀。*
