## 二、白拿的那 1000 万，怎么领

路径很短：进活动页 → 找到「01 新客尝鲜」→ 点「免费领取」，页面写的是**实时到账**。

门槛得看仔细，据公开的活动规则和实测攻略：

- **仅限活动期间新注册的账号**，老用户没有份
- 一个账号限领 1 次，同一自然人多开账号也只算一次
- 需要实名（姓名 + 身份证），有网友反馈领取时还要人脸验证；**不用绑银行卡**
- 量包总量有限，先到先得
- **到账后只有 30 天有效期**

那个模型是智谱的 GLM-5.3-Flash，1024K 上下文。官方给的应用场景写着「代码生成、AI4S、科研辅助、数据分析」——这跟别家送 Token 时的「聊天问答」不太一样，一看就是冲着开发者和科研场景去的。

1000 万够干什么？跑一批长文档、把 API 接进自己的小工具里试一圈、压一轮测试集，都够了。**不适合当长期饭票。**

## 三、1 毛钱的 5000 万，为什么值得看一眼

严格说这一份不算「免费」，是 **0.1 元**。但我还是把它放进来了，因为 20.5 元的东西卖 1 毛，跟白送差别不大。

据公开实测攻略，这排秒杀**每天上午 10:00 开抢，当日库存有限，卖完只能等第二天**；同一自然人在活动期内限购 1 次（这条各家口径略有出入，下单前看页面提示）。主打款就是截图里那两个：DeepSeek-V4.1-Flash-1017 和 GLM-5.3-Flash，都是 5000 万量包、1024K 上下文，二选一。

**这一毛钱买的不是额度，是一次把流程跑通的试错机会。**

很多人想试试「用 API 调大模型」，卡在第一步：注册、建 Key、改配置、发第一个请求，中间任何一步报错就放弃了。有个几乎不要钱的量包摆在那儿，你才愿意动手把它走完。走完这一次，后面换哪家平台都是同一套动作。

至于 Kimi-K3 那个 39 元、Qwen3.8-Max 那个 20 元，属于正常折扣，别因为「同一页」就顺手一起拍了。

## 四、四个坑，比额度更该先看

这个系列的老规矩：先把边界说清楚，再教你怎么领。这一页上的坑，有四条。

**第一，截止日有三个口径，别赌最后一天。** 官方页顶部写活动时间 **2026.08.13 ~ 2026.11.10**；两张 0.1 元卡片上却贴着「**截止到 11 月 14 日**」；另有第三方实测文写的是「延期到 11 月 10 日，还剩 4 天」。三个说法对不上，我不替官方猜。**按最早的 11-10 准备，把 11-14 当意外之喜**，领之前一律以页面当日显示为准。

**第二，30 天有效期，领了别吃灰。** 领完截个图发朋友圈、然后让它躺到过期，这是很多人跟免费额度的全部交集。量包不是资产，是张会化的冰棍。

**第三，也是最坑的一条：赠送 Token 优先扣，扣完自动转扣现金余额。** 官方规则写得很白。你要是往账户里充过钱，量包见底那一刻就开始扣真金白银。**不想花这个钱，就在额度用完前停手**，或者干脆别充值。

**第四，API Key 得建对地方。** 有实测攻略提醒：Key 要在 **Token Plan 专区**里创建，前缀 `sk-tp-` 开头才抵扣量包，在普通专区建的 Key 不吃这个福利。这条只有一家提到，我没法替它打包票，动手时自己核一眼页面说明。

按我这个系列的「保质期」判据，这一波属于**第二档：打进账户的赠品**，不是写进定价页的 0 元。判断依据和分档方法写在 [免费也分「保质期」：我把白嫖过的渠道按寿命分成了三档](../免费大模型系列/261101-免费也分保质期-白嫖过的渠道按寿命分三档.md) 里，这里只给结论：**只用来跑验证，别用来跑生产。**

## 五、一个搞超算的，为什么跑来送 Token

这才是这张页面最有意思的地方。

一家手里握着超算中心的平台，为什么要摆摊卖 1 毛钱的 Token 量包？是突然想做大模型了吗？

**不是。因为大模型调用的本质，就是算力。**

你跟模型聊一句，背后是显卡在算。别家卖 API，得先去租算力、再在上面跑模型；而超算互联网手里本来就有国产深算智能加速卡和全国一体化算力网——**相当于发电厂自己开了个充电站**，电是自家发的，边际成本天然低一截。

所以你在这页上看到的模型，智谱的 GLM、DeepSeek、阿里的 Qwen、月之暗面的 Kimi，没一个是它自己训的。它做的是**把这些模型接进自己的算力池，再按 Token 量包卖出去**。据环球网等媒体报道，这个「MaaS 特惠活动」今年 8 月上线，官方说法是「降低大模型与智能体调用门槛、扩容 AI 生产力供给」的算力普惠活动，生态伙伴里有中科星图、ChatExcel、安恒信息。

**看懂这一层，你就知道该拿它当什么了**：它不是要跟模型厂商抢生意，是要让闲置算力有活干。活动免费额度本质是**拉新预算**，预算花完就收口——这也解释了为什么它同时有 30 天有效期、截止日、限新用户、先到先得这一整套限制。

说白了，还是那个判据：**标价能谈，红包会烂。** 真要长期用，去定价页上找那个不会变的 0 元；这类量包，拿来跑通流程、验证想法，最划算。
