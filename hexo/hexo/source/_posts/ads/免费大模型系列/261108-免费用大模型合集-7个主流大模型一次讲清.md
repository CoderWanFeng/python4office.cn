## 二、能长期用的，和随时会没的，不是一回事

这张表里最容易被跳过的，是「到什么时候」那一列。

我薅过二十几个渠道，最后发现判断一个免费能活多久，其实只看一件事：**这个「0 元」写在哪一页。**

- 写进厂商**定价页**的 0 元，是**价格政策**。改一次要发公告、要挨骂，成本高，所以它能长期在。
- 打进你**账户**里的赠品 Token，是**红包**。它有到期日，而且绝大多数写着同一句话：过期作废，不补发、不延期、不重置。

标价能谈，红包会烂。

**所以你会看到**：智谱每天 3 亿、腾讯 Hy4 的 0 倍率，数字大得吓人，一个是「每天 19:00 领、次日 09:00 清零」，一个白纸黑字写到 11-15 23:59；反倒是 gpt-oss、MiniMax H3 这种一个 Token 都没送的，把模型文件下载进自己电脑，谁也收不回去。

这不是厂商小气，是两笔账：**定价页上的 0 元是拿来做长期生态的，赠品是拿来做短期拉新的**。拉新预算花完，口子就收。看懂这一层，你就不会再把「每天送 3 亿」当成资产。

按这个判据，这 7 个可以分成三档：

| 档 | 特征 | 这 7 个里谁在 |
|---|---|---|
| **能长期依赖** | 定价页 0 元，或权重在自己手里 | DeepSeek 网页端、gpt-oss、MiniMax H3、智谱 Flash 系列 |
| **有到期日** | 赠品 / 限免 / 0 倍率活动 | 智谱每天 3 亿、Hy4（11-15）、Qoder 千问（**目前仍可使用**） |
| **已经没了** | 官方公告下线 | GitHub Models（7-30 整站退役）、硅基流动 9B 永久免费、智谱 1024 的 5 亿 |

第三档每一条，当年都有人当成「永久」在用。GitHub Models 那次最典型：下线前先搞了两次故意降级的演练，才动手关站。信号早就给了，只是没人盯着公告看。

## 三、免费的代价，得先说在前面

合集最容易写成「七个都能白用，快去领」。但这个系列一直不是这么写的，这篇也不破例。三条得先摆出来：

**第一，0 倍率不等于无限量。** Hy4 那次界面小字写得很清楚：每日赠送免费额度，订阅用户享更高配额；免费用户只有少量体验额度，用完仍可继续消耗积分。标题说「免费了」没错，但你按「无限用」去规划，第三天就会撞墙。

**第二，免费渠道可能拿你的数据。** DeepSeek 那条带 `-free` 后缀的渠道，说明里写着免费期间对话数据可能被用于训练下一版模型。个人项目、学习、写点开源工具，随便用；手里有真不能外传的内容，别往免费口子里塞。**这才是「免费」二字背后真正的代价：你省下的是 token 钱，付出去的是数据。**

**第三，聚合平台别乱接。** 那种「一个接口薅 26 家」的目录里，混着来路不明的「免费 GPT-5 / Grok」，可能是影子 API，存在模型掉包风险。想省事，用 OpenRouter 里明确标 `:free` 的模型（免费账户每天 50 次请求、每分钟 20 次），或者干脆把开源权重放本地——**权重是唯一厂商收不回去的免费**。

所以要真给个用法，就一句：**挑一个能长期用的当兜底，再挑一个额度大的跑重活，够了。** 别把精力花在每天蹲点领红包上，那玩意儿明天可能就没了。
