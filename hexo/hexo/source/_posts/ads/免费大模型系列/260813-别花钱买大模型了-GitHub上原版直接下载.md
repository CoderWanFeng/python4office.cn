## 花钱买免费的东西，这件事有多离谱？

你可能会想："9块9嘛，也不贵，买个方便。"

我给你算笔账。

2025年春节DeepSeek爆火之后，36氪做了一次调查。淘宝、闲鱼上搜"DeepSeek"，出现了5类生意：

- **卖安装包**：Chatbox + Ollama，两个都是免费开源软件，打包卖9.9到19.9元。有单店销量超**20万份**，收入超**200万元**。

- **卖硬件**：鼠标键盘贴个"DeepSeek"标签，399元一个，卖了**23万单**。

最离谱的是，有记者暗访时，商家直接说了一句：**"卖的就是信息差。"**

不是模型，不是技术，不是服务——卖的是"你不知道这东西免费"这件事。

**这些人赚的钱，不是技术的钱，是信息差的钱。**

## 为什么大厂要"白送"大模型？

说到这里你可能有一个疑问：大厂花几十亿训练出来的模型，凭什么免费给你？

**答案是：开源不是做慈善，是一门更聪明的生意。**

你想想，Android系统免费开源了十几年，Google亏钱了吗？没有。Android免费 → 手机制造商都用 → 用户都装Google服务 → Google靠搜索广告和应用商店赚钱。**免费的是系统，赚钱的是生态。**

大模型也是一样的逻辑。DeepSeek把R1开源之后，华为云、阿里云、微软Azure、亚马逊AWS全抢着接入。这些云厂商用自己的算力跑DeepSeek的模型，向用户收算力费。DeepSeek自己也有API服务，因为模型是自己训练的，成本比任何人都低，定价只有GPT-4的**五十分之一**。

**模型免费 → 开发者都用 → 生态做大 → 云服务和企业版赚钱。** 这条路子，和Android一模一样。

所以你会发现一个规律：真正有实力的大厂，反而更愿意开源。因为开源不是"送"，是"种"。种子免费撒出去，长出来的森林还是自己的。

而那些把开源模型下载下来打包卖9块9的中间商呢？他们既没有训练模型的能力，也没有提供算力的基础设施。他们做的事情，翻译成大白话就是：**把公园门口的免费传单收过来，贴个"VIP专享"标签，卖你10块钱。**
