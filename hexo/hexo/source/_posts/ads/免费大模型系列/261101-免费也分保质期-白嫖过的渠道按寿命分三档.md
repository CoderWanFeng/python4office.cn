上周有个读者在后台问我，说他照着我的教程接了个免费 API，跑得好好的，某天早上起来直接调不通了。

我一看就明白了——他踩的坑，我自己也踩过不止一次。

这个系列写到现在 20 多篇，我薅过的渠道少说十几个。今天不教你怎么领，就讲一件更值钱的事：**怎么在领之前，就判断出这个"免费"能活多久。**

## 一、判据只有一个：看这个「0 元」写在哪一页

这句话是整个系列的底层逻辑，记住它，能省你很多事：

- **写进厂商定价页的 0 元** → 这是**价格政策**。定价页上不会写有效期，因为厂商没打算改它。改一次要发公告、要被骂，成本很高。
- **打进你账户里的赠品 token** → 这是**赠品**。它有到期日，而且绝大多数写着同一句话：**过期作废，不支持补发、延期或重置**。

一个是你进去就能看到的标价，一个是塞给你的红包。

标价能谈，红包会烂。

所以我把白嫖过的渠道，按"能活多久"分成了三档。

## 二、第一档：能长期调（写进定价页的）

这一档的特征是：官方定价页白纸黑字写着 0 元，没有有效期栏。

| 平台 | 免费的东西 | 限制 |
|---|---|---|
| **讯飞星火** | Spark Lite 定价页明写 **0 元/百万 tokens** | 个人实名，QPS 只有 2 |
| **百度千帆** | ERNIE-Speed、ERNIE-Lite 永久免费 | 有限速（Speed QPS=50） |
| **腾讯混元** | 混元 Lite 长期免费，不限调用量 | TokenHub 入口 |
| **智谱 GLM** | GLM-4-Flash / 4.7-Flash / 4.6V-Flash / Z1-Flash 等 Flash 系列输入输出全免费 | 免费层并发 1 |
| **DeepSeek** | 网页端 + App 对话长期免费，无消息上限 | API 侧要另算 |
| **火山方舟** | 实名后每天自动发 200 万 tokens | 模型需在控制台手动开通 |
| **魔搭社区** | 每天 2000 次免费 API 调用 | 单模型约 500 次/天 |

**敢把"永久"两个字写出来的，全网只有讯飞一家**——2024 年 5 月就官宣了 Spark Lite API 永久免费，到现在定价页上还是 0 元。其余几家用词都很克制："长期""计划长期开放""永久公测"。

这个措辞差异不是文字游戏，是**厂商给自己留的退路**。而厂商留的退路，就是你的风险敞口。

## 三、第二档：有到期日（打进账户的赠品）

这一档额度通常都很大，大到让人上头：

| 平台 | 额度 | 有效期 |
|---|---|---|
| **阿里云百炼** | 每模型 100 万 tokens，70+ 模型合计约 7000 万 | **90 天** |
| **百度千帆**（新人） | 每模型 100 万 tokens | **3 个月** |
| **腾讯混元**（新人包） | 每模型 100 万 tokens | **1 年** |
| **DeepSeek**（新用户） | 500 万 tokens | **30 天** |
| **火山方舟** | 单模型 50 万基础额度 | 长期，但需手动开通 |

**这类额度千万不要当成"你的"。** 它是厂商给你的一次试用，用完就没了，而且到期不补。

我自己的教训就在眼前：[智谱 1024 那 5 亿 tokens](../zhipu/261024-智谱送5亿Token-1024程序员节免费领.md)，10/24 晚上 8 点领、23 点生效、10/27 早上 9 点一刀清零，**没有延期**。三天之内从"5 亿随便造"变成 0，连个招呼都没打。

所以我给你一条硬规矩：**第二档只用来跑验证，不用来跑生产。** 真要长期跑，先在第一档里找个能兜底的。

还有一个坑：火山方舟的"安心体验模式"是**一次性**的，关掉之后无法再开。手别抖。

## 四、第三档：已经没了（我亲眼看着它消失的）

这一档最扎心，因为每一条当年都有人当成"永久"在用。

| 渠道 | 曾经的承诺 | 现状 |
|---|---|---|
| **硅基流动** | "9B 以下模型永久免费" | **已取消**，只剩 embedding / 语音 / OCR / 翻译 / 图生图 |
| **GitHub Models** | 免费调用各家旗舰 | **2026-07-30 整站退役**，playground、目录、推理接口全线关停，**已在使用的账号一并停掉** |
| **Cerebras** | 永久免费层 | 改成一次性 5 美元额度，且需绑卡 |
| **Gemini CLI** | 个人账号免费 | 2026 年 6 月起不再免费 |
| **MiniMax M3.1 Flash** | 免费版 | 10/22 下架 |

GitHub Models 那次最典型：7 月 16 日、7 月 23 日两次 brownout（故意降级演练），7 月 30 日整站下线。**演练两次才动手**，说明这事儿人家想了很久，只是你没看见信号。

**判断一个渠道快没了，看这三个信号：**

1. **额度突然变小**——从 1000 万变 500 万，从不限变限量
2. **开始要求绑卡**——免费的东西要你押证件，就是要收口了
3. **官方数字不再更新**——页面上那个"剩余额度"很久没动，或者公告停更

中两条，就该准备退路了。

## 六、正确的姿势：一个兜底 + 一个冲刺

别把所有希望押在一个渠道上。我的建议是：

- **兜底位（1 个）**：从第一档里挑一个，接进你的项目里当默认。讯飞 Spark Lite 最稳，就是慢（QPS=2），适合低频任务；要快就上智谱 Flash 或千帆 ERNIE-Speed。
- **冲刺位（1~2 个）**：拿第二档的大额度跑重活，比如批量处理、跑测试集、压测。**但要有心理预期：它随时可能没。**
- **永远留一条离线路径**：模型权重本身是免费的（[GitHub 上原版直接下载](260813-别花钱买大模型了-GitHub上原版直接下载.md)），这是唯一厂商收不回去的免费。

一句话：**用标价，别用红包；用政策，别用活动。**
