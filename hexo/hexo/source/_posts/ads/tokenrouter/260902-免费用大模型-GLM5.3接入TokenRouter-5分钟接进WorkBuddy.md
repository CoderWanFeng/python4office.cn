## 先说清楚：这次免费的是 GLM-5.3-Free（共享算力）

打开 TokenRouter 这个网站（https://www.tokenrouter.com/），首页挂着一条横幅：GLM 5.3 Free。
![](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/20260904095639806.png)

点进模型列表，能看到一个独立的模型：`z-ai/glm-5.3-free`，输入、输出价格都是 **0 美元**。

注意，这次上的是 `glm-5.3-free` 这个独立模型档位，标价 0 美元。但它是**共享算力**的免费版，**不是付费版 GLM 5.3 本体**——理论上调用的是同一套模型权重，但响应速度、并发稳定性都要打个折扣，高峰期偶尔会排队。

GLM 5.3 是智谱 8 月 28 日刚开源的新旗舰，主打两件事：**智能体编程**和**网络防御**。智谱 CEO 唐杰晒过一组数据：GLM-5.3 Flash 在 AA 综合智能指数拿到 57 分，以大约百分之一的前沿模型价格，登顶 OpenRouter 周榜第一。

| 对比项 | GLM 5.3 本体（付费版） | GLM-5.3-Free（这次免费版） |
|---|---|---|
| 标价 | 输入 $1.4 / 输出 $4.4（每百万 token） | 输入 $0 / 输出 $0 |
| 上下文 | 1M | 1M |
| 算力 | 独享 | 共享，高峰期可能排队 |
| 响应速度 | 快 | 相对慢，长任务等几十秒是常态 |

简单算笔账：按官方付费版价格折算，每百万输出 token 理论价值约 28 元人民币。但 Free 版是共享算力，能不能稳定跑出这么多量，要看当时的排队情况——免费是真免费，别按付费版的吞吐来预期。

**但丑话说在前面**：官网没有公布免费截止日期，也没写总额度上限。计费方式那栏写的是"Pay as you go"（按量付费），只是当前单价是 0。

说白了，它随时可以改价。所以我的建议是：**当它是限时体验，别当它是长期饭票。**

## 5 分钟接入：跟着做就行

流程就三步：注册 → 拿 Key → 填进工具。以 WorkBuddy 为例，其他 AI 工具的思路完全一样。

### 第一步：注册并生成 API Key

打开 www.tokenrouter.com，用邮箱注册一个账号（支持国内邮箱）。

登录后进后台，找到 **API Keys** 页面，新建一个 Key，复制保存好。

**这一步最关键**：注意 Key 只在创建时显示一次，关掉弹窗就找不回来了，先存到备忘录里。

![](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/iShot_2026-09-02_21.27.01.png)

### 第二步：把三项信息填进 WorkBuddy

打开 WorkBuddy，进入 **设置 → 模型 → 添加自定义模型**，填三个东西：

| 配置项 | 填什么 |
|---|---|
| API 地址 | `https://api.tokenrouter.com/v1` |
| API Key | 上一步生成的那串 |
| 模型名称 | `z-ai/glm-5.3-free` |

![](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/iShot_2026-09-02_21.27.29.png)

两个细节别踩坑：

- **`z-ai/` 这个前缀不能丢**。少打一个字符，请求直接报错。
- **模型名称别手打，复制粘贴**。`glm-5.3-free` 和 `glm-5.3-flash` 是两个不同的模型，前者免费、后者半价收费，看仔细。

填完点测试，返回成功就通了。之后在 WorkBuddy 的模型选择器里切换到它，就能用 GLM-5.3-Free 干活了。

### 第三步（可选）：其他工具同理

因为 TokenRouter 走的是 OpenAI 兼容接口，**任何支持"自定义模型"的工具都能接**：

- Trae：设置 → 模型 → 自定义，填上面三项
- OpenCode：配置文件里加 provider，同样三项
- Codex / Claude Code 类工具：改 Base URL 即可

一个 Key，全工具通用。

### 我实测下来的感受

配置完之后，我让它干了三件事：写周报、改一段批量重命名脚本、总结一份长文档。

体感上最明显的是**能用，但不算快**。简单任务（写周报、改脚本）响应速度还能接受，长文档总结就明显比付费版慢，等上几十秒是常态。

但有两个使用细节要提醒你：

- GLM 5.3 会**默认开"深度思考"**，思考过程本身也消耗 token。好在免费期间 token 不要钱，但如果你在意等待时间，简单任务可以忽略，复杂任务就让它想，反正质量更高。
- 免费模型是**共享算力**，高峰期偶尔会排队。我试的几次都秒回，但如果某天它突然慢了，不是你配置错了，是人多了。

另外一个真实感受：接入自定义模型这个动作本身，比想象中简单太多。以前总觉得"接 API"是程序员专属操作，实际上整个流程就是**复制、粘贴、点测试**三步。这一步迈出去，你的 AI 工具就从"包月套餐"变成了"自助餐"。

## 为什么能免费？聊聊背后的门道

有读者可能嘀咕：智谱自己官网也有免费模型，这个第三方网站凭什么免费给旗舰？

**这里有个值得记住的 AI 知识：模型聚合路由。**

TokenRouter 是一个"模型网关"：它把智谱、DeepSeek、通义千问等十几家模型，整合到一套 OpenAI 兼容的接口里。你只维护一个 Key，就能在不同模型之间随时切换。

![](https://raw.githubusercontent.com/CoderWanFeng/img-cdn/master/iShot_2026-09-02_21.26.48.png)

它的商业模式是赚差价和渠道费——而新模型上线时，模型方为了拉新，会给平台方一批推广额度。平台拿这批额度做"限时免费"，既帮模型方拉了用户，也给自己导了流。

**你免费用的是旗舰，平台赚的是人气，模型方赚的是装机量。三方各取所需，这才叫可持续的免费。**

但也要清醒一点：你的请求会先经过 TokenRouter 的服务器，再转发给智谱。它官方宣称零数据留存（Zero Data Retention），只记录请求元数据。

我的原则是：**个人练手、公开项目、学习用途，放心用；公司业务代码、客户数据、没公开的文档，别走任何第三方中转。** 这不是信不信任谁的问题，是链路上客观多了一个能看见你数据的环节。
