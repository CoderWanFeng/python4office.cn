不用办双币卡，不用找代充，不用自己去海外官网开户。

## 一、先把话说准：微信买的是额度，不是买下 GPT

严格讲，你不是「买了一个 GPT」，而是用微信买 WorkBuddy 国际版的**套餐或积分**，再用这些额度去调用列表里的模型。

模型是平台统一接进来的正版接口，你不用自己填 API Key、不用管海外账单、不用跟美元结算打交道。

这个区别值得说清楚：市面上那些「合租号」「代充 Key」，卖的是来路不明的账号；我在[免费也分「保质期」](../免费大模型系列/261101-免费也分保质期-白嫖过的渠道按寿命分三档.md)里写过影子 API 掉包的风险。

这里是客户端内的正规订阅——钱付给平台，平台给你额度，模型和账单都摆在明面上。

## 二、国内网络能不能用：过一次门槛，之后直连

这点最容易被说满，我按公开教程的原话拆开写：

| 环节 | 网络要求 |
|---|---|
| **首次登录 / 注册** | 官方教程原话：可能需要特殊网络环境 |
| **首次成功之后的登录、日常使用（大部分功能）** | 不需要，国内正常网络直连 |
| **实测跑通** | 有第三方教程在国内正常网络环境下正常使用 GPT-6-Astra |
| **客户端网络设置** | Settings 里「网络代理」默认为「直接连接」 |
| **界面语言** | Settings → General → Language → 简体中文，切完立刻生效 |

所以准确的说法是：**首次要过一道门槛，之后是直连**，不是「从头到尾完全不用管网络」。

各地网络情况不一样，第一次没打开别急着下结论，这一步得自己试。

顺带说一句，这一步也是它跟「自己翻出去注册海外账号」最大的区别：那边是每次都得折腾，这边是一次性的。

## 三、微信怎么付：价格和坑一起给你

| 项目 | 公开资料记录（核实于 2026-11-04） |
|---|---|
| **支付方式** | **微信支付**；国内银行发行的信用卡 / 借记卡；银联、VISA、MasterCard |
| **实测支付** | 招商银行双币信用卡（银联 + MasterCard 双标）正常付 |
| **套餐** | 分个人 / 企业，按月 / 按年；**年付 8 折** |
| **Pro 定价** | **10 美元/月**，或 **96 美元/年** |
| **免费试用** | **7 天**，赠 500 基础积分；需绑有效卡验证（扣一笔小额后全额退回） |
| **单独买积分** | 500 积分 **16.36 美元**（含税） |
| **税费** | 支付页显示约 **9%** |

操作路径很短：左下角头像 →「升级套餐」→ 官网订阅页 → 选套餐 → 付款方式选微信支付。

两个提醒，比价格更重要：

1. **7 天试用要绑卡**。不打算续订，至少在试用结束前 1 天取消，别等扣款了才想起来。
2. **价格、税率、赠送积分、免费名单都会变**。上表是公开教程与订阅页在 2026-11-04 的记录，以官网当日显示为准。

一句话：**微信解决的是「能不能付」，没解决「值不值」。** 值不值，得看下面这张倍率表。

有个细节别忽略：不同教程里 Gemini 的版本号写得不一样（一份标 3.5-Flash，一份标 3.8-Flash），Grok 也只在部分列表里出现。**这不是谁写错了，是列表一直在加新。** 具体有哪些，以你客户端当日右下角那张表为准。

一句话回答第三个问题：**不只是 GPT，Grok、Gemini 都在，连国产的 DeepSeek 和混元也能在同一个下拉框里选。**

第一件事，别下错：

## 六、照例泼冷水

1. **首次登录那道门槛还在**。别信「全程零门槛」的说法，第一次能不能顺利打开，各地不一样。
2. **微信能付 ≠ 便宜**。10 美元/月再加约 9% 税，高倍率模型烧积分很快；先用低倍率的「口粮」，别拿旗舰写周报。
3. **免费名单和倍率会调整**。今天 0.00x 的那几个，下个月未必还在，看到就先用，别收藏了事。
4. **数据走海外节点**。写稿、做表格无所谓；公司机密、个人敏感信息，套用一句老话：上什么山，唱什么歌，自己掂量。
5. **别把「免费」当长期饭票**。免费额度是钩子，付费才是长期方案——这也是我在[免费也分「保质期」](../免费大模型系列/261101-免费也分保质期-白嫖过的渠道按寿命分三档.md)里分三档的原因。
