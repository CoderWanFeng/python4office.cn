## 一、全程不用国际网络：从下载到日常，我一次没折腾

先把实话说前面：**我这台机器从下载、注册、登录，到每天开客户端调 GPT、Grok、Gemini，全程都用家里的国内宽带，没挂过任何网络工具。** 装完就直接用了，第一次也没卡。

这里要跟我 10 月那两篇对一下口径。那两篇我是照腾讯云开发者社区教程写的，写成了「首次访问可能需要国际网络环境，注册完成后日常使用可直连」。官方文档这么写是稳妥，先把最坏情况告诉你；但我自己的实际使用里，**那道「首次的门槛」根本没出现**。这次按亲历更正。

| 环节 | 实际情况 |
|---|---|
| **下载安装** | 官网直连下载，Mac / Windows / Linux 都有安装包 |
| **注册登录** | Google / GitHub 授权，国内网络完成 |
| **日常使用** | 直连，调 GPT-6、Grok、Gemini 都是 |
| **客户端网络设置** | Settings 里「网络代理」默认「直接连接」，我没改过 |
| **第三方交叉验证** | 有公开教程在国内正常网络环境下跑通 GPT-6-Astra |
| **界面语言** | Settings → General → Language → 简体中文，切完立刻生效 |

不把话说满的部分我也讲清楚：官方教程那句「可能需要国际网络环境」还挂在那儿，说明少数网络环境、或者某些时段，确实有人第一次打不开。**这是概率问题，不是必答题。** 真遇到了，先换网络（手机热点、换个 DNS）或者过一会儿再试，别一次失败就认定「必须翻墙」。

这也是它跟「自己注册海外账号」最大的区别：那边是每次都得折腾，这边我是一次没折腾。

顺带说清楚，它是两个网站、两套账号：国内版 `workbuddy.cn` 用微信 / QQ 生态登录、以国产模型为主；国际版 `workbuddy.ai` 用 Google / GitHub 登录，才有 GPT、Grok、Gemini。积分互不通用，别装错了来问我为什么没看到模型。

## 三、「腾讯的产品」这句话，怎么验证

「安全合规」「不用担心跑路」这种话，喊一百遍不如把可查的东西列出来：

| 怎么看 | 公开依据 |
|---|---|
| **产品归谁** | 腾讯云开发者社区教程原话：「WorkBuddy 是腾讯推出的 AI 编程工具」；官方 X（@WorkBuddy_AI）发布过定价与模型调整公告 |
| **钱付给谁** | 客户端内正规订阅，账单与发票走腾讯云控制台；官方支持邮箱是 `workbuddy_ai@tencent.com`、`workbuddy@tencent.com` |
| **合规体系** | 腾讯云公开的 WorkBuddy FAQ：作为腾讯云产品继承其安全合规体系，列有 ISO27001、ISO27018、ISO27701、CSA STAR（金级）、等保三级/四级、PCI-DSS、SOC 等；HTTPS 全链路加密、文件沙箱隔离、启动时默认只读、体验优化计划可手动关闭 |

所以「不用担心跑路」这句话，我更愿意换个说法：**主体清楚、账能查、出了事找得到人**。至少不用怕一个来路不明的小站哪天把服务一关、预付余额也没处要。

但我得把边界划清楚，不能替官方打包票：

上面那些认证和沙箱说明，是**腾讯云 WorkBuddy 产品层面公开的文档**；国际版 `workbuddy.ai` 的账号体系、服务节点和数据流向跟国内版不是一套，我 10 月那篇就写过「数据走海外节点」。写稿、做表格、折腾代码无所谓，公司机密、个人敏感信息，套用一句老话：上什么山，唱什么歌，自己掂量。

「合规」是产品和流程的事，不等于你往里传什么都合适。这两件事别混。

## 七、照例泼冷水

1. **别把「我不用」说成「人人都不会遇到」**。我这边全程国内网络，但官方文档仍写着「首次访问可能需要国际网络环境」，少数网络环境下第一次打不开是有可能的，自己试一下最准。
2. **7 美元是首月价，不是长期月费**。次月起 10 美元/月，年付折合 8 美元/月；定价页还挂着个 20 美元的划线价，跟 10 美元的口径对不上，官方没解释，做预算只认结账页。
3. **首月优惠每人一次**，试用过就没了；连续包月不退款，取消要提前至少 5 个自然日。
4. **微信支付标的是「适用地区可用」**，能不能在结账页选到，以当日实际展示为准，别当成板上钉钉。
5. **数据走海外节点**。合规认证是产品层面的公开说明，不等于敏感信息可以随便传，自己掂量。
6. **模型列表、倍率、Pro Only 标签都会变**。今天这张截图是 11 月 11 日的，下个月未必一样。
7. **别拿旗舰写周报**。倍率表里最便宜的那几个，才是过日子的用法。
